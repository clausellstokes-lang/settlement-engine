**How to read this register.** One word carries one meaning on each surface (a code token, a persisted value, a DM sentence, a scrutiny page, the map). Each row names the WORD, the MEANINGS FOUND on the surfaces where it occurs, and the RULING. FREE = no literal on master `81f1cd963` in `src/` and `tests/` (a count is given where there are hits); LANDED = reused in its landed meaning only; HOMONYM = another meaning on another surface, registered and compound-scoped. Each program volume's own token register is of record for its census and its rows (PL §2 · MN §3.4 · RN §2.4 · CH §2.3 · PT §2.4 · PS §15 · ST §2.3 and §2.5 · PR §15.2 · BD §2.6 · OP §16 · MG §16 · WS §14 and §2.5 · FS §16); this register closes the list across volumes, names the cross-surface homonyms, and lists every WITHDRAWN name so that no text mints it again. Identifiers, flags and code values are machinery: none appears in a DM sentence, and a scrutiny word is shown in its prose form. The register runs in five parts: THE CORPUS WORDS; THE PROGRAM VOLUMES' TOKENS, one block per volume; THE MAP REGISTER; THE SHARED KEYS, LADDERS AND STORES; and the REINFORCE binding.
