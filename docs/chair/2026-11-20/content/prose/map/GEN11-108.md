# GEN11-108: the two routes into DS-GEN-11's contradiction pool

Measure-only (PROSE-1 helper, 2026-11-20). No source changed.

## The route function

`src/domain/display/stateProse/generalStateProse.js :: criticalIssuePoolKey(count, recordClean)` picks the pool `criticalIssueCount: critical contradictions on the record` when `count > 0` **or** `recordClean === false`, picks `criticalIssueCount zero` when the count is 0 and `recordClean === true`, and returns null for a non-number count or for count 0 with `recordClean` undefined. Its caller `src/components/new/generalDeskRead.js :: generalDeskLines` passes `economicViability.metrics.criticalIssueCount` (the number of `economicViability.issues[]` with severity `critical`) and `recordCleanOf(r)`, which is `true` when the receipt's `record_coherence_battery` judgment is `pass`, `false` when it is `needs_review`, and `undefined` when it passes but the record carries any by-design row (`byDesignItemsOf`).
