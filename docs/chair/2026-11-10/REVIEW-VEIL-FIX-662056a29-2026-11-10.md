## Findings (all low, none blocking)

### 1. LOW — 208 does not evaluate the sanitizer once; the pin proves it for a different kind of function

- **Where:** `supabase/migrations/208_party_link_independent_idempotent_veiled.sql:20, :199, :216`; pin at `tests/security/galleryUnlisted.pglite.test.js:401-425` (the counting twin is declared `volatile` at `:408`).
- **Reproduction.** I replaced the sanitizer with a stand-in that counts its calls through a sequence and loaded the tip's `get_unlisted_dossier`.
  - Stand-in declared `immutable`, as the real sanitizer is: **2** evaluations per read, at the blocked tip and at this tip alike.
  - Stand-in declared `volatile`, as the lane's twin is: 2 at the blocked tip, **1** at this tip.
- **Why:** a subquery holding only an immutable call is flattened into the outer query, and the call is repeated at each use. A volatile call stops that, which is what the pin measures.
- **Consequence:** cost only, the same as at the blocked tip. The header and the pin state something that is not so.
- **Smallest cure:** `offset 0` inside the lateral subquery, and count with an immutable twin. Or drop the claim.

### 2. LOW — the snapshot strip raises when `$veil` is an array, and it removes one key rather than admitting a known set

- **Where:** `208…sql:197`.
- **Reproduction** (overrides written directly to the column, then the link read):

  | Stored overrides | Returned overrides |
  |---|---|
  | `{"$veil": []}` | `ERROR: path element at position 2 is not an integer: "snapshot"` |
  | `{"$veil": "x"}` | `{"$veil":"x"}` |
  | `{"$veil": null}` | `{"$veil":null}` |
  | `{"$veil": {"snapshot": "…"}}` | `{"$veil":{}}` |
  | `{"$veil": {"v":1,"deltas":[],"copy":{"secrets":[…]}}}` | the same, `copy` included |

- **Reach.** The client's write clamp only ever stores `$veil` as an object with `v, deltas, mode, at, snapshot`, so both rows need an owner writing the column by hand, against their own town. The array case breaks that town's link (it did not at the blocked tip). The last row means the header's "nothing but what HIDES travels" depends on no future writer adding a second payload key.
- **Smallest cure:** strip only where `jsonb_typeof(overrides -> '$veil') = 'object'` (executed: the array case then returns unchanged). An allowlist of `$veil`'s keys would be the fail-closed form.

### 4. LOW — the blank class is written with raw invisible characters in three SQL files

- **Where:** `206…sql:265`, `207…sql:200`, `210…sql:197`.
- **CONFIRMED (read and executed).** The class holds raw U+00A0, U+1680, U+2000–U+200A, U+2028, U+2029, U+202F, U+205F, U+3000 and U+FEFF. It works: all 17 read blank. A line-splitter that honours U+2028 and U+2029 sees two more lines in each file than a newline count does, and an editor or formatter that normalises whitespace would change the class without a visible diff. The lane's pin exercises the no-break space only.
- **Smallest cure:** spell the class with `\uXXXX` escapes, as the client does. Executed: the escaped class gives the same answer for all 17 blanks and for the five non-blank cases.
