- **Recall** (`recall.mjs`): every reader line whose `mechanism` maps to the kind (`mech.mjs`: a = "names a house, a role or a force the town lacks"; b = "presumes normal times under a crisis in force"; c = "a size"; the field is a guide, not a key) is looked up in that town's tip dump; a test "fires on the line" when it hits the dump line that holds the sentence.
- **Precision** (`sample.mjs`): thirty distinct lines a kind, drawn by a fixed stride across the 720 (none of them the readers' towns), each read against the town's record. A town-weighted check follows it: the twenty largest writers by towns, each read (a draw by distinct line can miss a writer that prints the same false line in 240 towns; one did, below).
- **Writers** (`writers2.mjs`): as ROUND-3-CUT traced them — the sentence carrying the trigger, the town's names, tier nouns and figures folded out, the longest fixed runs (the one with the trigger first) searched with `git grep -F -i` in `src/` and `docs/content` of the counted tree; a generated pool is named by pool, combination and variant; a data table by its constant and first key; code by its nearest top-level definition. Composed rows with no fixed run (the flow card's house lists) are traced to the surface by an anchor of its code. The view breaks ties (an Economics line goes to the economy generator before a data table that happens to hold the same words).
- **Holders** (`holders.mjs`): each lane's files changed since its own merge base with the line; where several lanes change a file, the lanes with commits of their own on it (ROUND-3-CUT's own-holders rule). "none" = no lane changes the file.
- **Known or NEW** (`report2.mjs`): a hit line is KNOWN when its sentence (names and figures folded) equals a cold line's, or shares the cold line's writer and 60% of its words; else NEW.

## The package (step 4, EXECUTED)

```sh
sh docs/chair/2026-11-13/probes/CENSUS-2/census2.sh <tree-root> <out-dir> [workers=4] [--files a,b,c] [--seeds <file>] [--reuse] [--count-only]
```

- Births every seed of `seeds.txt` (the 720) in the tree, renders every dossier (the first census's walk), counts every kind against each town's record, traces each hit to its writer in that tree, joins holders (`holders.at-count.json`, or `HOLDERS=`) and the cold lists (read from `origin/lane/round-3-cut-2026-11-13` in that tree when fetched, or `COLD_CUT=`/`COLD_INC=`), and writes `hits.json`, `hits.by-file.json` (writer file → holders → kinds → functions with towns, lines, known and NEW, one example) and `counts.txt` (one row a pattern, one a writer file). `--files a,b` prints only the hits whose writer is in those files. `--seeds seeds.readers.txt` counts the readers' 80 towns; `--count-only` stops before the trace.
- It reads every stage's own exit (births, each render worker's own `EXIT` line, the dump count, the counter, the trace, the report) and exits non-zero on any failure or on an empty count; nothing is read through a pipe.
- **Measured:** births and render of the 720, **10 m 21 s** on 4 workers (the first census's script, the same render); the readers' 80, 98 s; count + writer trace + report of all eight kinds, **107 s**. **A from-scratch run of `census2.sh` on the 720 at 9e57f5023: 12 m 12 s, exit 0** (births and render 618 s, count, trace and report 114 s), every kind's hit count identical to the run above.
- Holders are a snapshot (`holders.mjs` re-reads them: `node holders.mjs <repo> origin/lane/integration-2026-11-07 <out.json> up=lane/... ...`).

## What the render covers, and what I did not measure

- **Covered:** the dossier's views as the owner sees them in the app (not read-only, premium): Summary (Overview, Foundations, Plot Hooks), Systems (Institutions, Services, Economics, Resources, Power, Defense, Magic, Outlook), World (NPCs, Relationships, Daily Life, Traditions, History, Rumors & News, War, Faith), every disclosure opened. Notes views are skipped by every test.
- **Not covered:** the PDF's text, the Foundry journal (which escapes brackets: the chair's note), the exports, the shared (read-only) page, the Tonight sheet (the increment's readers rendered it; the census's own render does not — 28 of their 1,962 lines are on it), the Compendium, anything a campaign tick or an edit changes after the first survey. A claim of zero here is a claim about the dossier's views only.
- **Not measured:** the readers' other mechanisms ("two homes that disagree" 386 lines, "a ruler, a power … that is not so" 139, "a resource, a good or a chain state" 140, "a figure against the record's" 47, "a count" 46): no kind of this brief covers them, and a fact read from the record cannot see two lines of the page disagreeing.
- **The 720 are not the readers' corpus:** the readers read the app's configuration shape (DEFAULT_CONFIG, Random off for crises); the census's 720 use every random dial and forced crises. A rate on the 720 is a rate on those births.
- **Writers:** a traced writer is the file and function a fixed run of the sentence was found in (EXECUTED); where one sentence lives in two files the view decides (PLAUSIBLE for those few).
