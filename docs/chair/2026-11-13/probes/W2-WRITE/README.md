# W2-WRITE — the writing lane's scratch tools, kept for the second seat

Paths inside are this seat's scratchpad (`/tmp/claude-0/.../scratchpad`: `lane/` the lane worktree, `base/` a
measurement worktree, `tools/` the census and layer-map probes extracted from their lanes); re-point `SP` first.
- `gaps.sh <tree> <out>`: the mapping seat's `depth.mjs` (lane/layer-map-2026-11-12) over the census's 720, then `caseprobe.mjs` (per case: the slots the desk fills, the dimensions it answers, each variant's eligibility alone, player and dm); `show.mjs <all.json> <pool>...` prints one pool's cases.
- `doors.sh`: the annex doors in order (projection, wiring census, projection, both `--check`).
- `iterate.sh <cause>`: the corpus fast set (`fastset.txt`), then `pins.py` (count pins re-keyed with the cause; the A0b debt; the histogram; the two annex anchors by their base text, `anchors.json`, keyed by the test file's line index) and `repin.mjs` (the shift register), to a fixed point; prints the reds beyond `base-reds.txt`.
- `bytes.mjs <car> <why>`: the prose byte baseline, node zlib level 9; a declared row only above the chain's end.
- `takeblocks.py`, `lib.py`: copy a block from a draft document; small edit helpers.
- `newlines.mjs <base-tree> <tip-tree>`: every new or changed corpus line, by pool (the owner's veto list).
