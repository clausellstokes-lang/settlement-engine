# W2-FIX-DATA-HISTORY's instruments (copied from the seat's scratchpad; re-made in minutes)

- Births, 1,540 in the app's shape: CENSUS-2's probes (`git archive origin/lane/census-2-2026-11-13 docs/chair/2026-11-13/probes/CENSUS-2`), with this `seedcfg.mjs` (CENSUS-2's, plus the fresh `w2fd4r`/`w2fd4s` 720) over `seeds1540.txt`: `TREE=<tree> OUT=<dir> SEEDS=seeds1540.txt node births.mjs` (about 60 s; it writes `corpus.ndjson.gz`). The census: `sh census2.sh <tree> <out> 4 --seeds seeds1540.txt` (or the default 720, with `--files` the six files); then `node mine.mjs <out>/hits.json [seeds.txt]` for the six files' hits.
- Record counters: `node rows.mjs <tree> <corpus>` (every row this seat cured), `culture.mjs` (each architectural detail by tier), `lead.mjs` (the shortage's lead against the income shares), `merch.mjs`/`tmplmk.mjs` (merchants and templates where no market stands).
- Diffs: `fielddiff.mjs <base corpus> <tip corpus>` (leaf by leaf, by family), `sentdiff.mjs` (what left, what came), `arrdiff.mjs` (arrivals by sentences changed), `readmoved.mjs` (30 moved births by stride), `readnew.mjs <tree> <corpus> history|arrival "<text>"...` (a crisis town, the smallest and the largest that print a line).
- Governing tests: `gov.sh <tree> <out.json> <list>` (a list of test files, JSON reporter), `govcmp.cjs <a.json> <b.json>` (title by title), `failmsg.cjs` (the red titles' diff lines). `eff.cjs <file>` (effective lines, the size ceiling's own count). `stale.mjs` (run in a tree: the presumed-things registers' stale rows). The ledger scripts are the hand-kept ledgers' edits as made (formatting byte-preserved).
