- **`_gallery_veil_join`**: a flat array keeps the old one-query form; a nested one is tokenised from its jsonb
  text. Tokens at brace depth 0 only; `{` reads `[object Object]`; `[` followed by `]` is one empty leaf; `null`
  reads ''; elements are grouped by the top level's commas and joined by `sep`, nested leaves by `,`. That is

  the id differential (ids up to 600 arrays deep) is 0 unequal.
- **`_gallery_veil_drop_hooks`**: the shallow walk descends only into children whose text holds a `"…hook…": `
  key, never below a dropped key, to depth 64; levels are contiguous, rebuilt deepest first from a per-parent
  map, so each level reads only the level below. Past 64 the token pass: a member runs from its key to the next
  `,`/`}` at its own depth (a value's own closing bracket is one deeper, so it cannot end the member early); a
  comma survives only between two survivors. The text pre-test cannot miss a key: a key is printed `"<key>": `
  with only escapes inside, and the case rules match the client's (`/hook/i` without the `u` flag folds ASCII
  only; PostgreSQL's `~*` folds the pattern's own letters). No hole.
