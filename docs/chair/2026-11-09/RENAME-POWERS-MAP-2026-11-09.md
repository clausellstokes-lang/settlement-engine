# RENAME-POWERS — the label map, in plain language (2026-11-09)

## In one minute

The engine calls the groups that run a town "factions"; the owner's design calls them "powers". This map renames what readers see and nothing else: the internal names and saved data stay as they are. There are about 570 printed uses. Most are plain swaps ("The Factions (3)" becomes "The Powers (3)"; "Governing faction" becomes "Governing power"). About thirty labels need a better word, because "power" would be repeated or say nothing: "Faction power" becomes "Strength of the powers", the Foundry's "Faction:" becomes "Member of:", and "Criminal faction:" becomes "Underworld:". Nine group names that contain the word get plain new names that say what the group is: the Reform Movement, the Inquiry, the Peace Party, Noble Claimant (Reform Line), the Independence Movement, "{Neighbour} Collaborators", "Rival gangs", "the secular camp" and "Word on the gangs". The placeholder names become "Unnamed power", and the "Faction Leader" title becomes "Leader". "Noble Claimant" stays, as the owner said. Towns already saved keep their old names unless the owner wants a migration. Every row can be vetoed with a word.

## What this map does NOT change

- **The engine's own wiring.** Field names, stored keys, file names, ids, telemetry and code names keep the word (`factions[]`, `factionId`, `faction_power`, `factionRename.js`, …). Readers never see these. 635 of the 1,221 measured strings (673 of the 1,282 words) are this kind, and they stay as they are. The owner put the data keys after the deploy.
- **The names in the slots.** Most lines that look like they say "faction" in the code actually print a power's own name ("Merchant Guilds", "War Council"). The sources audit counted 63 in `factionDynamics.js` and 71 in `npcGenerator.js`, and almost all of those are this. They print no retired word, so there is nothing to rename.
- **Towns already saved.** A saved town keeps the names it was made with. A town saved with a "Reformist Faction" will still show that name. New towns get the new names. A DM can rename any power with the existing Rename tool. Changing saved towns too would need a save migration, which is data work. **My default: no migration.** The chair can rule otherwise.
- **Names that never had the word.** "Noble Claimant" stays (the owner's word); only its bracket changes. "War Council", "The Independent Bloc", "Revolt Leadership" and the like are untouched.
- **The share card's brand line.** The owner kept that word on 03:5x (answer 13). It stays.

## Part C — The written lines (the sentences, not the labels)

There are **about 460 sentences** across the generators, the annexes, the pools, the pulse, the help and the explanations. For these the rule is the same everywhere:

1. "faction" → "power", "factions" → "powers", "faction's" → "power's". *"Two or three factions each run part of Haifeng"* → *"Two or three powers each run part of Haifeng."*
2. "factional" is reworded, because "powerful" would mean something else. *"Factional politics"* → *"Politics between the powers"*; *"factional split"* → *"split between the powers"*.
3. Where the swap would put "power" next to "power", the line is reworded by hand. *"No faction holds enough power to move against the seat"* → *"No power is strong enough to move against the seat."* 55 such lines are flagged "reword by hand" in the appendix.
4. Lines whose `{faction}` slot prints a power's NAME are not touched, because the reader sees the name and not the word.
5. **Where another lane is already rewriting the whole sentence** (SW-6 crisis surfaces, SW-7 power-side generators, SW-11/SW-12 the pulse, SW-B4 the PDF), the swap goes into that lane's new sentence. SW-8 swaps only what no other lane touches. That way no sentence is rewritten twice.
6. The annex lines (the 13 `docs/content/RECEIPT_POOLS_*.md` volumes behind the `*.generated.js` files) change in the annex and are regenerated through the manifest's door. The `.js` files are never edited by hand.

## Open questions for the chair (each with my default)

1. **Saved towns.** New towns get the new names, and saved towns keep "Reformist Faction" and the rest. *Default: no save migration (it is data work, and the owner put data after the deploy). The DM can rename by hand.*
