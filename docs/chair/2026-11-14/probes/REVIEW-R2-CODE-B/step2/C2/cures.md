## Method
- Births of the 7 reproducible row towns at tip and Q (`rows-*.ndjson.gz`). rww-thorp-under_siege-1 is not a births.mjs shape, so its class was read on the 1536.
- `ctext.mjs` dumps every crisis line on the page (summary, hook, cast, absent, stakes, levers, see-first, if-nothing) plus the crisis plot hooks, per town, at each tree (`all-{q,tip}.ct.jsonl`). `verify.js` checks it against the tip dumps.
- Each class is checked against the record:
  - `defchk.js` / `defall.js`: defence buckets and house heads.
  - `treat.js`: treater roles.
  - `trad.mjs`: Traditions admission, plus the Overview market line.
  - `summ.mjs`: the writer's own atoms (grain, prosperity, market, route: isolated, crisis: hunger).
  - `least.js` / `only.js` / `hit*.js`: house members, ranks, the lever, stakes.
  - `seat.mjs`: tip's isSeatVacant, plus the Power page.
  - `temp.js`: the temporary cards.
  - `plague.js`: the slot holder's role and healers on the roster.
- Removals: line sets diffed Q vs tip per town, then read against the tip record and tip page dumps.
