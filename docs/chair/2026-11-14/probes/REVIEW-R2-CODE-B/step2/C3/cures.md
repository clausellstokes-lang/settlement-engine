## Method
Read-only scripts in this folder, one node process at a time: iter.mjs streams the births; sent.mjs, chains.mjs, npcdoor.mjs, src1.mjs, cutrows.mjs call the TIP's own leaves (chainHousesOf, chainSourceOf, chainPrintName, institutionHouseLabel, houseLabelsInText) on tip records; access.mjs/access2.mjs diff q/ against tip/ chainHousesOf on the same records; absent.mjs, absentQ.mjs, absent30.mjs, absentkinds.mjs handle (d); toll.mjs and toll720.mjs handle the toll; pdfchain.mjs checks PDF » rows against the roster; strip30.mjs diffs the changed Q-vs-tip label lines; tabgrep.sh counts per tab. I birthed row towns at the tip (rw3-* w2a3 towns, rr2s-* cut towns) and at Q for the rw3 set.
