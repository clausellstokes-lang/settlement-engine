## Method (scripts in /tmp/claude-0/-home-user-settlement-engine/a2e70bbe-8ee3-5a4b-b408-20d6830901c8/scratchpad/helpers/H1/)
- `scan.mjs`: for every birth, `composeTonightSheet`, `composeSettlementQuickGuide`, `cultureScopeLine`, `foodBandOf`, `isSeatVacant`/`seatKeeperOf`/`keeperFormOf` and `factsOf` -> scan.jsonl (scan-more.jsonl for the 550 extra births).
- `castcheck.mjs`: every cast person on the sheet, own goal or pool line (matched to CAST_WANTS by pattern) -> castrows.jsonl / castrows-more.jsonl.
- `scopecheck.mjs`: every Overview scope line's clauses against the live roster, factsOf (market, walls, water, ruler), size band, resources, route.
- `journal.mjs` + `jbr.js`: the Foundry canon journal for all 1536, catalogue brackets by page; crisis-page lever counts inline.
- `dumpcheck.mjs`: the tab dumps: Overview Food Security vs Daily Life tile vs foodBandOf; Economics "Short:" vs band; Via and Outlook brackets; toll renames by route; the vacant seat's keeper form vs the Power tab; help text; badges (-> dumpcheck.json).
- `tcmp.js`: the printed Tonight sheets (surf-tip *.tonight.txt) equal scan.jsonl's composition (357/357 identical when read).
- `more-seeds.txt` / `more.ndjson.gz`: the 550 extra births (tools/births.mjs).
