## 3. AS SIMULATION SUBSTANCE

**The engine finally runs up as well as down, and honestly.** Booms are named compositions of
real trade throughput; reconstruction debits real ally credit; satellites are conserved
population transfers; the calamity bucket is genuinely type-blind with the strike budget
preserved under exposure loading. The belief→decision→consequence chain is closed end-to-end
(rumors → banded beliefs → Blainey margins read in both directions → typed reasons → sue-for-
peace → treaties → strain → revanchism), and the momentum threshold law holds *mechanically* —
the politics surveyor verified every psychology factor is floored; there is no absorbing state
in the slice. War homeostasis is closed (feasibility → exhaustion scar → age drain → hard
ceiling), conservation is audited two-sided with war dead as the only sink, and force ≡ organic
is structurally enforced through shared kernel resolvers, not asserted.

**The incoherence that remains is concentrated and nameable — cross-wave contract enforcement:**
- **The dead are not dead** (high): "movers skip remnants" is enforced nowhere outside the two
  lifecycle modules — upswing can arm reconstruction on a corpse, the annual calamity draw can
  re-strike a ruin for a "0 dead" beat, flourishing could found an Academy on a grave.
- **The navy lobotomy** (high): naval transit records never retire — one arrived convoy locks a
  navy out of all future operations forever, and blockades have no organic end (peace lands, the
  strangulation persists and keeps feeding the peace reason that already fired).
- **Same-tick clobber in a constitutional kernel** (high): upswing's `freshSettlement` reads the
  pre-clone array its sibling kernel correctly avoids — cross-arc writes silently lost,
  completed reconstructions re-armable.
- **Advertised transitions that cannot fire**: convergence's occupation-on-overstay is designed,
  tuned, and pin-tested, but intervention records are deleted the tick their contest resolves;
  the one-army law is enforced in only one direction; a DM's casus decree survives exactly one
  tick; boom cooling is dead code (booms can only end in crisis); settlementPolitics' two "who
  does" inputs read fields no engine code writes (plus an operator-precedence bug), so the
  external-threat rally and alignment kinship never fire.
- **Conservation frays**: same-tick multi-receiver generosity overdraws the hard reserve floor
  (the designed triage is built and unconsumed); the upswing's repayment fold double-decays the
  obligations ledger; a dead parent strands its satellites outside Σ-conservation.

None of these threaten determinism — every one produces the same wrong bytes on every run. That
is exactly why they survived fifteen green gates: the constitution proves *reproducibility*, and
these are reproducible incoherences. The counterpart criterion held everywhere *except* the one
verb whose dial is a placeholder (FORCE_RECONSIDERATION refuses on every UI-staged order — the
momentum wave's counterpart is dead at the surface).

## 4. AS PRODUCT / EXPERIENCE

**The engine has outrun the eye — confirmed, and now enumerable.** The one-mover-one-read-model
contract (articulated by this codebase's own display layer) is breached by the five newest
ledgers: politics blocs and covert conspiracies, foreign interventions, the credibility stock,

wave is "about 90% delivered at the surface where the DM actually lives."

**The trust surfaces have the sharpest product bugs.** Two highs sit on the commerce funnel's
narrowest points: the primary AuthModal closes itself when the user presses Enter to submit (a
failed sign-in can never show its error — sibling modals carry the one-line guard it lacks), and
the wizard save flow never stamps save identity into the store, so the owner-ruled free-tier
ladder (save → $2.99 durable right) dead-ends while duplicate save clicks burn the three free
slots and the exit dialog claims an already-saved draft is unsaved. Two more highs drop DM
intent silently: a clock-bound queue refusal rides through `applyEvent` shaped like success (the
composer resets the form for an order that never queued — live for the entire duration of a
parked pause), and the docket's edit lane inverts a queued cult *removal* into an *imposition*
(editSeed is a hand-maintained reverse of buildEvent with zero test coverage). The map autosave
key diverged from its own chip's fingerprint, so drag-edits show "Unsaved changes" forever and
are discarded on campaign switch. And two analytics calls ship raw user data (a Supabase userId,
free-typed search text) past the privacy floor the analytics program built.

Where the surfaces ARE wired, the product is unusually legible — cause chains as sentences,
refusals that teach, empty states as invitations, receipts in house voice everywhere, and the
newest read-models (treaty documents, climb-down receipts, misjudgment news) are excellent. The
gap is coverage, not craft.
