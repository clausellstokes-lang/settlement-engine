## §1 · THE BEHAVIOUR THIS MEMBER ADDS

Today a creed can leave the realm entirely and **the realm's own chronicle says nothing.**
Executed at this base, and this is the wave's whole premise:

```
qualifyingTier(1,'cult') = cult        qualifyingTier(0,'cult') = cult
advancePantheon({pantheon:{'deity:Pale':{seats:1,tier:'cult'}}, snapshot:<Pale holds nothing>})
  → changes: []
  → pantheon: {'deity:Pale':{wins:0,losses:0,seats:0,tier:'cult',tierHeld:0}, …}
```

⛔ **A one-seat deity is ALREADY `cult`** — `MINOR_PROMOTE` is 2 — so when it loses that seat the
tier does not move, `changes` is **empty**, and `synthesizePantheonArcs` emits nothing. The two
existing realm arcs key on tier crossings (`change.to === 'major'` / `change.to === 'cult'`) and
**can never see a seat count.** The last altar in the realm goes out in silence.

⚠ **AND THE PRODUCTION FILE CLAIMS OTHERWISE.** `realmEvents.js:218-219` reads: *"A deity falling
TO 'cult' (or losing its last seat — extinction) is 'The Twilight of X'."* The parenthesis
describes behaviour that does not exist. M2 corrects the sentence in the same commit.

WF-1c makes the realm-scale ending **legible**: when a creed's seat count reaches zero and the tier
ladder has nothing left to say about it, one realm-scope `pantheon_extinction` entry fires — once,
on the crossing tick — naming the creed the realm no longer keeps. Dark, nothing changes at all.

## §2 · THE CURE

### 2.1 ⭐⭐ THE FIRE PREDICATE IS A DERIVATION, AND A LITERAL WOULD BE A STOP

The charter's *"seats 1 → 0"* is not loose shorthand for *"any seats → 0"*. Executed, a **major**
deity collapsing 4 → 0 in a single tick behaves like this:

```
tick 1: changes=[]                                                   sun={seats:0,tier:'major',tierHeld:1}
tick 2: changes=[{deityId:'deity:Sun',from:'major',to:'cult'}, …]    sun={seats:0,tier:'cult',tierHeld:0}
tick 3: changes=[]                                                   sun={seats:0,tier:'cult'}
```

⛔⛔ **THE SEAT LOSS LANDS ON TICK 1 AND THE TWILIGHT ON TICK 2.** A predicate of
`prevSeats > 0 && seats === 0` would emit a realm-scale extinction on tick 1 **and** a realm-scale
twilight about the same deity on tick 2 — **two obituaries, one tick apart, for one event.** That
is the charter's *"distinct from tier demotion"* read backwards.

**The predicate is therefore the case the ladder cannot narrate:**

```js
const lostLastSeat = prev.seats > 0 && seats === 0;
const ladderSpeaks = qualifyingTier(seats, curTier) !== curTier;  // the module's OWN pure function
const lastSeat     = lostLastSeat && !ladderSpeaks;
```

| fixture | `ladderSpeaks` | beat |
|---|---|---|
| 1-seat `cult` → 0 | `qualifyingTier(0,'cult') === 'cult'` ⇒ **false** | ⭐ **fires** |
| 4-seat `major` → 0 | `qualifyingTier(0,'major') === 'cult'` ⇒ **true** | **silent**; the Twilight covers it |
| 1-seat `minor` → 0 (inside the dwell) | `qualifyingTier(0,'minor') === 'cult'` ⇒ **true** | **silent**; the Twilight covers it |

⛔ **NO LITERAL THRESHOLD IS AUTHORED, AND THAT IS LOAD-BEARING RATHER THAN TIDY.** ODQ §308.3
**RAISED-4** forbids a literal threshold where a constant is in scope, and **`MINOR_DEMOTE = 1`
sits in `pantheon.js`'s module scope** — so spelling the charter's `prev.seats === 1` would be a
STOP by coincidence of value, cured by nobody because it would read as correct. `> 0` and `=== 0`
are the presence and absence of seats rather than bands, and the tier question is delegated
entirely to the module's existing `qualifyingTier`. **RAISED-4 is satisfied BY CONSTRUCTION**,
on WF-1B's `KEEP` precedent.

⭐ **AND THE TWO ROW KINDS ARE PROVABLY MUTUALLY EXCLUSIVE PER DEITY PER TICK.** Read at
`ratchetPantheonTiers` (`:342-358`): a deity whose `qualifies === curTier` takes the
`matured: false` branch and its dwell resets to 0, so no tier change can land for it this tick.
`lastSeat` requires exactly that condition. ⇒ no deity can carry both rows in one tick, which is
what makes the "no double obituary" claim an invariant rather than a timing accident. A6 asserts it.
