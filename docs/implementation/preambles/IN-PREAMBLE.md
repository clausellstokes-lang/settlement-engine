## §I8 · Mutant hygiene

Test trust on an IN wave is proved with **disposable source mutants in an isolated immutable
candidate**, never with a standing mutation-manifest row where the acceptance filenames sit outside
the enforced nomenclature and directories.

For every mutant, in this order:

1. prove the **source bytes actually changed** (a no-op plant is a STOP);
2. require a **nonzero test exit** and the **named acceptance title** red — a red under a different
   title is an ambiguous mutant and a STOP;
3. restore the **exact pre-mutant SHA-256**;
4. rerun focused green.

⛔ **Do not run the estate-wide shared-tree sweep**: `src/` carries other lanes' uncommitted and
untracked work, and a sweep plant's `git checkout --` revert is exactly the parallel-session hazard
the dirty-tree guard refuses.

**Anti-vacuity rules that have each bitten this volume:**

- ⛔ A **redundant second guard subsumes the first** — a mutant that passes every arm means the
  assertion had a second, unnoticed enforcer, not that the code is safe.
- ⛔ A **count mutant on a literal goes vacuous**.
- ⛔ A **fixture that mirrors the deriver can never see a dead arm** — boot the real producer through
  the real lane, never a shortcut fixture.
- ⛔⛔ **A RENDERED-SURFACE NEGATIVE PASSES WHEN THE SURFACE NEVER RENDERED** — the IN family's own
  minted idiom. **The cure is a POSITIVE PRESENCE PIN STANDING BESIDE THE NEGATIVE, in the same
  test, on the same rendered text**, plus a **mutant control** proving the scanner convicts a
  planted violation. A green scan over an empty string is worse than no scan.
- ⛔ A **self-referential pin** (a list compared against itself) proves nothing.
- ⛔ A **fixture spelled against a name an adapter has already translated away** silently produces an
  empty result and greens a vacuous pin. **Spell fixtures against the RAW ledger row, then let the
  adapter rename.**
- ⛔ A **new negative assertion is not proved until the anchor walker is green** (§I7).

- ⛔ **Trust no exit status you did not capture in-shell.** Redirect to a file and read `TRUE_EXIT=$?`.
- ⚠⚠ **THE LYING EXIT IS A LIVE CLASS**: a long gate can outlast its window, background itself, and
  have the harness report the **wrapper's** exit 0 over a red gate. **An exit not read from the
  gate's own tail is no receipt** — and the cure is to **outlast the gate in your own turn**.
- `npm run check` is a long `&&` chain. A red step blacks out every later step; the receipt must say
  **which steps actually ran**.
- ⛔ A **failing enforcement walker is never banked as ordinary test debt** — a failing test is debt,
  a failing walker is a **disabled guard**.
- **A pre-existing red is an EMPIRICAL claim**: derive the list from the test-ratchet baseline
  **whole**, never from memory. ⚠ The family has already shipped a packet whose pre-existing-red
  list named two legitimate reds and **missed a third**, making its expectation of exit 0 wrong at
  compile time and at landing.
- ⛔ **Never raise a baseline, budget, timeout or ceiling to finish a packet.**
- The final full gate is a **bare** `check:tail` with a true exit, plus a **separate** `smoke:boot`.
  Under a train, both move to the terminal commit and are run once there.

## §I10 · The census law under IN

Three censuses move on an IN wave and every one is an **exact-equality** pin. A member states each
live figure and each required post-change figure, both re-executed at its own base.

1. **The whole lighting census** — the tuple *files / parked / credited / test titles / suite
   titles*. It is **re-derived WHOLE in ONE run**, never patched, in the same change that moves any
   figure. ⚠ **The sequence hazard is live**: while any arm is red the census **stops measuring**, so
   later arms may read anything. ⭐ Probe with a temporary `console.log` **inside the existing census
   test, before its first assertion**, so it mints no title and cannot move what it measures.
   ⛔ **`.each`, looped or conditional registration, nested describes, `skip` and `todo` are
   forbidden in an IN acceptance file** — a `.each` case is invisible to this census by construction
   and **the WHOLE FILE parks**, so the arithmetic still closes while `credited` silently does not
   move. **Verify `credited` moved, not just `files`.**
   ⭐ **Renames and added assertions inside an existing case are census-neutral** — the census counts
   titles, not their text. Registering one more title is not.
2. **The registry / routing censuses** — the registry list, the registered-kind count, the routed
   tokens, and **both arithmetic identities**. ⚠ **The two counts do NOT always move together**: a
   no-desk row registers without routing by design and raises the divergence by exactly one; a
   desk-bearing row moves both and leaves the divergence untouched. **A member states which of the
   two shapes it is and predicts every affected numeral by name.** ⛔ Any numeral moving in a
   direction the packet did not predict is a STOP.
3. **The runtime denominator** — the total test count and the frozen known-failure ceiling.
   ⚠ **Runtime is NOT census titles.** A registry whose walker registers per-row through `.each`
   adds runtime cases with **zero** census titles; a registry walked by a plain loop inside one test
   adds **none**. **A member derives its runtime delta from the registration shape it is actually
   joining, and never by assuming it equals its title delta.**

⛔ **The census-holder rule.** At most one in-flight wave holds the census. A member confirms with
the chair that it is the holder, and STOPs if a foreign lane holds uncommitted test titles at
re-record time or holds the census walker dirty at dispatch. **Never census a live shared tree.**
Under a train the **train** is the single non-terminal holder; ⭐ in a **single-member** train the
whole re-derivation happens in the same commit that creates the test file, so the walker is green at
every commit of the chain and there is no interior red to declare.

⚠ **THE CREATE-SPELLING RECONCILIATION.** A packet's `CREATE` paths become **existence-checked at
the LANDED flip**. Reconcile every `CREATE` spelling against the landing commit's own
added-files list **before** the flip; a rename during implementation moves the manifest row in the
same change or the flip throws.

## §I11 · Standing STOP conditions

In addition to `PACKET_STANDARD.md` §"Mandatory STOP conditions", an IN member stops — **without
expanding or repairing** — when:

1. packet status is not READY, or HEAD is not the verified base or an ancestry-proven descendant
   admitted by the dispatch machinery;
2. authority bytes, a target SHA-256, a required symbol, a CREATE-target absence, or a
   foreign-dirt fingerprint differs from the packet; or **any porcelain entry is NOT explained by
   `git diff HEAD` being empty** — that is real foreign WIP; reserve it, do not work around it;
3. a target file is dirty, changed concurrently, or outside the manifest;
4. **live code refutes state ownership, lifecycle, durability or stage ordering — the code wins and
   the packet stops**;
5. the manifest would need one more handwritten file, one more registration file, a further
   acceptance title, or an **inherited** override (§I3);
6. any hot file's measured effective count would move, or any size-baseline entry, ratchet, budget,
   timeout or ceiling would need raising;
7. the `title=` census or any deep-craft kill-list ceiling moves;
8. any registry, routing, census or runtime denominator differs from the exact figures the packet
   states, **including one moving in an unpredicted direction**;
9. the unlayered baseline would need a line, or the argued roster an entry (§I2) — the layer row is
   the only lawful cure, and it is a chair act;
10. a **new cross-layer pair is measured** that the packet did not design — a source-repair STOP,
    never a registry or baseline edit;
11. a kind-pool walker reds on a **reachability arm** — a pool carries a slot the engine cannot
    supply. The answer is a chair correction to the annex (§I1), never an invented slot value and
    never a padded pool;
12. **a Herald desk that does not exist becomes necessary**, or a beat would ride the catch-all
    fallback without an explicit dated interim declaration (§I3);
13. any edit to `docs/content/RECEIPT_POOLS_INFORMATION.md` appears necessary;
14. **a derivation would need to receive `worldState`**, a second counterpart-keyed record read
    would open outside the gate-owning leaf, or a second `=== true` read of a flag appears (§I4);
15. a frozen closed record shape would need another key, a closed band ladder another member, or a
    basis vocabulary another token — each is pinned by exact equality and at least one is a
    cross-program contract;
16. the OSR scan implicates a **schema mint**, or a new observed-shape finding appears — report; do
    not mint, do not baseline, do not `--write`;
17. the news-authoring walker gains a new debt row, or a per-file authoring-site count moves without
    being named in the manifest;
18. a **new persisted key, ledger sub-key, state family, writer, flag, tuning key, stage, migration,
    dependency, golden, registry, route, icon or preset** would be needed — ⛔ **a durable record
    where none exists is owner-gated and is refused at the member level**;
19. a committed **golden moves** — that is a premise refutation, never a re-record;
20. **dark mode changes** reference identity, news, ledger bytes, scorer output or call-path
    dormancy in ANY dark spelling — absent, explicitly false, or lit-with-no-record;
21. a foreign lane holds uncommitted test titles at census re-record time, holds the census walker
    dirty at dispatch, or the chair has not confirmed this packet is the in-flight census holder;
22. ungoverned Vitest concurrency, a recursive sealed runner, a failed or ambiguous mutant, an
    incomplete restore, or a nonzero validator/gate/smoke occurs;
23. a **tuning value proves unavoidable** — report the measurement and stop; **the number is the
    chair's** (§I12);
24. any soak, tuning, deploy, push, migration, marketplace, paid-policy or legal work would begin.
    **None of these is ever implied by an implementation packet.**
25. a **delete, retire, remove or strike clause** would execute without an executed consumer census
    proving the target dead — the law is stated in full immediately below;

> **THE DELETE-CLAUSE LAW (OWNER_DECISION_QUEUE §38.4).** A charter's delete, retire, remove or
> strike clause **executes ONLY after an executed consumer census proves the target dead.** The
> census is run by the member that would perform the deletion, at its own verified base, and its
> receipt names the walked corpus, the denominator, and every surviving consumer by path. ⛔ A clause
> is not a measurement. A charter sentence saying a thing is dead is a **premise to be tested**,
> never a licence to delete — and when the census refutes it, **the code wins and the packet stops**,
> with the clause struck or re-aimed at a named derived subset rather than obeyed.
>
> ⚠ Three same-shape refutations on one day are why this is law and not advice: a retirement that
> was a live behaviour change, an operand that was never evaluated, and a deleted disjunct feeding
> two ratified same-seed goldens. Each was caught by an executed census; none was visible in the
> charter prose.
>
> ⭐ **A deletion whose census comes back CLEAN still records the census** — the receipt is what lets
> the next wave trust the absence instead of re-deriving it.

The STOP report contains the smallest measured contradiction, the evidence, and a proposed packet
split. **It contains no speculative repair.**

## §I12 · Values, flags, and what is never an implementer's

- **§42/§43 — VALUES ARE CHAIR-SIGNED AT PROMOTION, ON AN EXECUTED DERIVATION.** *A value without an
  executed derivation is a promotion STOP.* ⭐ A member that authors **zero numbers** lands without a
  value signature — the cheapest posture available and the one to aim for. Transcribing an
  annex-verbatim corpus, re-deriving a census, and indexing a ladder **positionally** are not
  authoring; typing a threshold, a cap, a band boundary or a window **is**.
- ⛔ **Module-local frozen tuning is not an escape from the tuning signature.** A number is a number
  wherever it is frozen.
- **§49/§50 — THE FLAG-MINT HABITAT CARRIES THREE OBLIGATIONS, ALL STANDING LAW.** A packet that
  mints an engine-gated flag pays: **(a)** the certification ordered-equality pin — the flag-manifest
  test file joins the manifest and its literal edits are priced; **(b)** the generated edge-shared
  bundles that the rules module feeds, rebuilt in the same commit, because the freshness gate is red
  without them; **(c)** ⭐ the flag drive spelled as a **LITERAL `<flag>: true`** in the acceptance
  file, because lit-coverage grants AUTO credit only on a literal and a computed key attributes to
  **no** key — the code is right and only the machinery is blind, which makes it the cheapest of the
  three to miss.
  ⇒ **A member that mints NO flag says so AFFIRMATIVELY and states that none of the three is
  incurred.** Silence reads as an omission, and two trains have now stopped mid-chain discovering
  one of the three.
