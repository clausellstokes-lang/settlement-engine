## §P3 · The census law under GR

Three censuses move on a GR voice wave and every one is an **exact-equality** pin.
A member packet states each live figure and each required post-change figure, both
re-executed at its own base.

1. **The whole lighting census** —
   `tests/lint/sovereigntyLightingContract.walker.test.js`, the tuple
   `files / parked / credited / test titles / suite titles`. It is
   **re-derived whole**, never patched, in the same change that moves any figure.
   The standing GR shape, held by four consecutive landings, is exactly
   `+1 file / +0 parked / +1 credited / +8 test titles / +1 suite title`:
   one new credited test file with **one literal `describe` and eight literal
   top-level `it` calls**.
   ⛔ `.each`, looped or conditional registration, nested describes, `skip`, and
   `todo` are forbidden in a GR acceptance file — a `.each` case is invisible to
   this census by construction.
   ⭐ **Renames and added assertions inside an existing case are census-neutral.**
   The census counts titles, not their text. Amending an existing pin's wording
   and widening its assertions moves no figure; **registering a ninth title
   does.**
2. **The registry/routing censuses** — `GRAMMAR_KIND_REGISTRY` rows,
   `GRAMMAR_RECEIPTS` pools, `GRAMMAR_HERALD_KINDS`, `EXACT_SECTION`
   (`ROUTED_TOKENS`), `kindPoolFloors`' `REGISTERED_KIND_COUNT`, the
   registered-minus-routed identity, the unvoiced-token backlog, and the
   underfloor frozen backlog. ⛔ `REGISTRIES` moving off **9** is a STOP.
3. **The runtime denominator** — the total test count and the frozen
   known-failure ceiling. ⭐ `grammarLifecycleKindPools.walker.test.js` runs
   **three `test.each(GRAMMAR_KIND_REGISTRY)` sites**, so one new registry row
   adds exactly **three runtime cases** while contributing **zero** census
   titles.

⛔ **The census-holder rule.** At most one in-flight wave holds the census. A
member packet confirms with the chair that it is the holder, and STOPs if a
foreign lane holds uncommitted test titles at re-record time or holds the census
walker dirty at dispatch. Under a train (`DESIGN_BUILD_EFFICIENCY.md` §2.3) the
**train** is the single non-terminal holder and the whole re-derivation happens
once, at the terminal.

## §P6 · Mutant hygiene

Test trust on a GR wave is proved with **eight disposable source mutants in an
isolated immutable candidate**, never with a standing mutation-manifest row: the
GR acceptance filenames sit outside the enforced mutation-test nomenclature and
directories, so no sweep row is owed.

For every mutant, in this order:

1. prove the **source bytes actually changed** (a no-op plant is a STOP);
2. require a **nonzero test exit** and the **named acceptance title** red — a red
   under a different title is an ambiguous mutant and a STOP;
3. restore the **exact pre-mutant SHA-256**;
4. rerun focused green.

⛔ Do not run the estate-wide shared-tree sweep: `src/` in this checkout carries
other lanes' uncommitted and untracked work, and a sweep plant's
`git checkout --` revert is exactly the parallel-session hazard the dirty-tree
guard refuses.

**Anti-vacuity rules that have each bitten this volume:**

- ⛔ A **redundant second guard subsumes the first** — a mutant that passes 7/7
  means the assertion had a second, unnoticed enforcer, not that the code is
  safe.
- ⛔ A **count mutant on a literal goes vacuous**.
- ⛔ A **fixture that mirrors the deriver can never see a dead arm**.
- ⛔ A **rendered-surface negative** passes when the surface never rendered.
- ⛔ A **self-referential pin** (list compared against itself) proves nothing.
- ⛔ A multi-line `// anchored:` marker counts only if its **last** line carries
  the marker, and the anchor must be the line **immediately above**.

## §P7 · Gate-reading law

- ⛔⛔ **Never read a gate through a shell pipe.** `npm run check | tail` reports
  the PIPE's exit status, not the gate's, and has greenwashed a red gate twice.
  Use `npm run check:tail`, or `sh scripts/gate-tail.sh <command...>` for any
  other gate command; both print the tail and exit with the gate's own code.
- ⛔ **Trust no exit status you did not capture in-shell.** Redirect to a file and
  read `TRUE_EXIT=$?`.
- `npm run check` is a **17-step `&&` chain**. A red step blacks out every later
  step; the receipt must say **which steps actually ran**.
- Report **both** TypeScript configurations by name and window:
  `typecheck:ratchet` (`tsconfig.full.json`) and `typecheck:domain:strict`
  (`tsconfig.domain-strict.json`). A ratchet being green is evidence only about
  that ratchet. A per-file `tsc` is a vacuum.
- ⛔ A **failing enforcement walker is never banked as ordinary test debt** — a
  failing test is debt, a failing walker is a **disabled guard**.
- If a full gate is red, compare failure **identities** against a committed-base
  run or an integrity-counted archive. Do not repair unrelated rows. Never land
  past unexplained red.
- ⛔ **Never raise a baseline, budget, timeout, or ceiling to finish a packet.**
- The final full gate is a **bare** `check:tail` with a true exit, plus a
  **separate** `smoke:boot`. Under a train, both move to the terminal commit and
  are run once there.

## §P8 · Standing STOP conditions

In addition to `PACKET_STANDARD.md` §"Mandatory STOP conditions", a GR member
stops — **without expanding or repairing** — when:

1. packet status is not READY, or HEAD is not the verified base or an ancestry-
   proven descendant admitted by the dispatch machinery;
2. authority bytes, a target SHA-256, a required symbol, a CREATE-target absence,
   or a foreign-dirt fingerprint differs from the packet;
3. a target file is dirty, changed concurrently, or outside the manifest;
4. live code refutes state ownership, lifecycle, or stage ordering — **the code
   wins and the packet stops**;
5. the manifest would need one more handwritten file, one more registration file,
   a ninth acceptance title, or an **inherited** override (§P2);
6. any hot file's measured effective count would move, or any
   `scripts/.size-baseline.json` entry, ratchet, budget, timeout, or ceiling
   would need raising;
7. the `title=` census or any deep-craft kill-list ceiling moves;
8. any registry, routing, census, or runtime denominator differs from the exact
   figures the packet states;
9. `kindPoolFloors`' `REGISTRIES` moves off **9**, or any numeral moves in a
   direction the packet did not predict;
10. the kind-pool walker reds on a **reachability arm** — a pool carries a slot
    the engine cannot supply. The answer is a chair correction to the annex
    (§P1), never an invented slot value;
11. any edit to `docs/content/RECEIPT_POOLS_GRAMMAR.md` appears necessary;
12. a **successor or roster lookup**, a grouped-instrument claim, a fabricated
    slot, a partial address, an unauthorized terminal voice, a duplicate beat, or
    a presentation failure that vetoes or rewrites mechanics is required;
13. the OSR scan implicates a **schema mint**, or a new observed-shape finding
    appears — report; do not mint, do not baseline;
14. `wizardNewsAuthoring.walker` gains a new debt row;
15. a new persisted key, state family, writer, flag, tuning key, stage, migration,
   dependency, golden, registry, route, icon, or preset would be needed;
16. a committed **golden moves** — that is a premise refutation, never a
    re-record;
17. dark mode changes reference identity, news, ledger bytes, scorer output, or
    call-path dormancy;
18. a foreign lane holds uncommitted test titles at census re-record time, holds
    the census walker dirty at dispatch, or the chair has not confirmed this
    packet is the in-flight census holder;
19. ungoverned Vitest concurrency, a recursive sealed runner, a failed or
    ambiguous mutant, an incomplete restore, or a nonzero validator/gate/smoke
    occurs;
20. any soak, tuning, deploy, push, migration, marketplace, paid-policy, or legal
    work would begin. **None of these is ever implied by an implementation
    packet.**

The STOP report contains the smallest measured contradiction, the evidence, and a
proposed packet split. **It contains no speculative repair.**
