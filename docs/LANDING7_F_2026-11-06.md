### The rule, as landed (`composedWalker.js` header, "A DECLARED ABSENCE IS CLAIMED BY SILENCE")

no third: (1) the field's own last segment declares absence (`absent`, `…Absent`) AND the pool's predicate holds it
truthy; (2) the variant carries an authored `no <fact>` mark and the field path names that fact. It is answered on
the REPORT channel, counted and printed in the shipped-corpus run. It is never dropped. The implicit-negation limb is
read first and is untouched. An absence-named field the predicate does not hold truthy stays an under-claim. A caller
that passes neither predicate nor marks (`prose-wave-gate.mjs :: qVocabularyReport`) reads as before.
