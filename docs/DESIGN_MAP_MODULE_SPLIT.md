### §11.1 · The GPL election — what it means mechanically (facts + the program's own recorded analysis; final compliance review stays with the counsel item)

1. **The module becomes GPL-3.0 and can never be re-closed** where it derives from third-party GPL code. Dual-licensing (§8 Fork 1) survives only for the owner's own untainted contributions; the derived portions are GPL forever. Elected knowingly, prelaunch.
2. **The module must live in its OWN repository from day one.** Once GPL code enters it, any distribution of a tree containing it carries GPL obligations — so it can never sit inside the private repo. Extraction (§2) now targets a separate repo, not a directory.
3. **The private product consumes the module's OUTPUT, never its code.** The boundary that keeps the full codebase private: the engine emits the serialized plan artifact (§2); the module — running as a separate program (build-time/generation-time renderer, separate process or service, or an isolated iframe origin like the existing map.settlementforge.com FMG-fork precedent) — consumes the plan and emits SVG; the product ships the SVG as data. A program's output is not covered by the program's license (standard position; counsel confirms). **The private client bundle must NEVER import/link the module's JS** — that is the combined-work trap §254.6 recorded.
4. **The core repo's no-GPL law (§248/§253/§254.5) is now load-bearing for the business model, not just prudence.** The owner's election REVERSES it for the module repo only; for the core tree it TIGHTENS: a single GPL-derived snippet in the core kills "keep the rest hidden."
5. **New lane-hygiene law:** clean-room inverts, scoped. Module lanes MAY now read GPL-3.0 source (TownGeneratorOS etc.). **A lane/context that has read GPL source may never write to the core repo.** Core lanes remain forbidden from reading GPL source. One lane, one side.
6. **Compliance floor for the public module repo:** GPL-3.0 LICENSE file · upstream copyright notices preserved on derived files (TownGeneratorOS © its author) · source published for everything conveyed · the §5 scrub list executed first. ⚠ Verify what GPL source actually exists before valuing the derivation: the ledger records TownGeneratorOS as GPL-3.0 standard text; the polished MFCG web app's source was never public (the dissection was behavioral observation for that reason). An inventory of actually-available GPL map generators is the module program's first research act.
7. **CLA before the first outside PR** (if outside contributions are ever accepted): contributions to the GPL module arrive GPL-only; the owner's private-use interest in future module versions needs contributor grants — or the owner simply treats the public repo as upstream-GPL and their private consumption stays output-only regardless (under §11.1.3 the output-only boundary makes this moot for the PRODUCT; it matters only if module code were ever to be linked privately).
