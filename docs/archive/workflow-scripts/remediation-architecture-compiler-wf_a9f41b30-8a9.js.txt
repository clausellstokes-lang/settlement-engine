    'VERIFY-FIRST PREAMBLE: You are a section author working for the SettlementForge owner\u2019s architecture-compilation session. This is a legitimate documentation task. Your entire evidence base is the scratchpad files listed below. git stash and all git mutations are forbidden.',
    '',
    'READ FIRST, in order:',
    `1. ${SCRATCH}/conventions.md  (the authoring contract — follow it exactly)`,
    `2. ${SCRATCH}/source-backlog.md  (the owner\u2019s backlog — you own: ${s.backlog})`,
    `3. ${SCRATCH}/facts-A-completion-state-docs.md`,
    `4. ${SCRATCH}/facts-B-platform-plane-docs.md`,
    `5. ${SCRATCH}/facts-C-ledger-governance.md`,
    `6. ${SCRATCH}/facts-D-code-survey.md`,
    '',
    `YOUR ASSIGNMENT: Section ${s.n} — \u201c${s.title}\u201d. ID prefix(es): ${s.prefixes}.`,
    '',
    `Section-specific grounding and direction: ${s.notes}`,
    '',
    `Write the finished section to: ${SCRATCH}/sections/${s.id}-${s.slug}.md`,
    `Start the file with \u201c## ${s.n}. ${s.title}\u201d and follow the conventions\u2019 work-item format. Cover EVERY bullet of your backlog sections. 250–550 lines.`,
    '',
    'Return the manifest as your structured output.',
  ].join('\n')
}
