**The instance (LANE DG, 2026-08-03, @ c3411038).** `tests/property/dispositionChannelsDormancyGolden.test.js` had three red `wr2-*` rows for ~162 commits. Its `projectionFor` hashed worldState + regionalGraph + wizardNews + saves + every per-tick trace of a DARK run, then froze that sha256 in `tests/fixtures/disposition-channels-dormancy-golden.json` (captured once @ 7796954e, never re-recorded). Its docstring premise — "captured before `dispositionChannelsEnabled` is wired anywhere" — had also gone stale: the flag now has 14 production read sites.

**Re-derivation method that settled it (reusable).** Check the capture commit out into a temp worktree, run a BYTE-IDENTICAL copy of the harness in both trees, and diff the two projections path-by-path. The capture-era tree reproduced all three stored hashes EXACTLY — which simultaneously proves the manifest was honestly captured AND that the forensic harness is faithful. Result: 578 differing leaves, **ZERO on a disposition-named path**; `dispositionStats` byte-identical, still `{losses,score,wins}`. Cause was WR-4/WR-5 (`warTerminationReads` gained trajectory/books/homeFront/ruler bands; news gained `war_trajectory_losing`) — all ungated by the flag. No leak.

**Why:** dormancy is a claim about the DIFFERENCE a flag makes, not about the absolute state of a world N commits ago. An absolute whole-world pin is moved by every unrelated feature, so a red row proves nothing about the flag — and because it reads as coverage, nobody re-scopes it; they just keep seeing red. It is the temporal sibling of [[self-referential-pin-class]]: coverage that cannot fail for the reason it names.

**How to apply — the FOUR-FENCE pattern for any flag-dormancy fence:**
1. **Own-footprint golden** (the only stored fixture): hash ONLY the state the feature solely writes, plus its own receipt kinds. Immune to unrelated evolution; moves on any extension while dark.
2. **Differential byte-identity**: ABSENT vs explicit-false over the whole projection. No fixture, so it cannot rot.
3. **Call-path spy**: `vi.mock` with strict PASS-THROUGH wrappers (rest-args in, original out) recording whether the feature's cross-module entry points fire while dark. This is the only fence that catches an UNGATED feature. Prove non-perturbation by deriving the re-recorded hashes independently from an unmocked standalone harness and matching them exactly.
4. **Gate-polarity census**: every production read is the strict `=== true` form, so ABSENT ≡ FALSE *by construction* at decision sites no state pin can reach. Strip block comments BEFORE strings — an inline `/** @type {{flag?:unknown}} */` cast is not a gate (this exact false positive fired). Carry a non-vacuity floor (≥10 strict reads, ≥5 files) + a loose-gate negative control.

**The mutant that validates the design:** flip the fixture LIT. Fences 1, 3 and the dark contract go red (56 lit ledger advances caught); **fence 2 correctly stays GREEN** — because a mutant lights both configurations equally. That green is the precise blind spot fences 1 and 3 exist to cover, and is the argument for never replacing an absolute pin with a differential alone.
