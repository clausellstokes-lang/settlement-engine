On 2026-07-27 the owner raised two AI-layer design questions in conversation (design judgment requested, no implementation):

**Q1 — telemetry for intent.** Should user-facing AI surfaces see usage telemetry (how users build, where use-cases gravitate) to infer intent more precisely — with the hard constraint that the AI must not remember the data after use?
Recommendation delivered: yes, as a versioned, id-free, k-anonymous **"intent atlas" bundle** modeled on aiGroundingBundle — hash-pinned, injected per request into stateless edge calls, so no-retention is a property of the architecture, not a policy. Guardrails: (1) schema gate proving zero user identifiers in the bundle; (2) **informs suggestion only, never engine math** — telemetry touching post-authoring engine behavior is queue-item-G1 territory and collides with [[the-promise-ratified]]; (3) new data flow registers in the E-D AI-wall census ([[enforcer-ed-aiwall-shipped]]); (4) doesn't ride BYOK calls to unknown vendors without disclosure. Sequencing: corpus doesn't exist pre-launch — spec now, light post-cohort.

**Q2 — model ceilings.** Owner explicitly does NOT want models flattened to a common denominator (an Opus should not have Fable's ceiling). Recommendation delivered: [[finite-semantics-law]] guarantees a uniform floor (typed buckets fail closed), so ceilings may vary safely — stronger models mean sharper inference and fewer clarification loops, never different world-truth. Two build pieces: a **generated AI charter** per surface (vocabulary/laws/exemplars derived from code, cache-friendly large stable prefix) and a **capability tier ladder** (context depth + thinking budget + multi-step permission mapped from model, priced in credits). BYOK tier assigned by a small competency probe at key registration, not by model name (extends the verify-by-test-call in [[dossier-editor-capability-atlas-verdict]]). Owner follow-up same day ("let the AI decide its ceiling itself") resolved as **demonstrated-not-declared**: introspective self-assessment is uncalibrated/stochastic/spoofable, so the probe assigns the ceiling; the model self-directs how much earned headroom to SPEND per request, with credit-consent at escalation — recorded in M43's ↻ REFINED row. The parked multi-step Surveyor-planning question is the top rung of this ladder — build substrate first, gate planning as a tier privilege under its own ruling.

**Why:** both are new-capability (owner-gated) decisions; neither is queued or built. The sharpest line to defend later: telemetry → AI suggestion → user confirmation is fine; telemetry → engine input is forbidden without a separate golden-shifting ruling.
