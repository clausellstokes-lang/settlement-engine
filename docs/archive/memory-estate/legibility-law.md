# THE LEGIBILITY LAW (owner doctrine, 2026-07-22)

Owner's words: "how can we completely simplify the system and the balance between simplicity with
coherency with comprehensivity is the measure and goal of legibility."

**The test:** a REGULAR HUMAN — not someone versed in spreadsheets — must be able to read and
navigate every surface, and each page must give AT A GLANCE complete and wholesome information.

**The balance (all three, never two):** SIMPLICITY (one glance = one plain-language truth) x
COHERENCY (the same concept reads the same way everywhere; no jargon door-names) x
COMPREHENSIVENESS (nothing hidden that the reader needs; depth via progressive disclosure, never
via omission). Legibility is the MEASURE of the balance, not a fourth goal.

**Applications ordered so far:** the Realm Inspector (owner questions its panel-per-page glance
value), Library discovery ("heavily streamline"), and by extension every surface. Sits alongside
[[finite-semantics-law]] (typed truth) and [[the-promise-ratified]] (deterministic truth) as the
third leg: LEGIBLE truth.

**Practical rungs (manager reading, vetoable):** plain-verb door names over jargon (Pulse/Oracle
class names need glosses or renames); a one-sentence plain-language summary atop every data panel
(what changed, what matters now); bands-over-bare-numbers where a number needs interpretation;
progressive disclosure (glance -> sentence -> table); the Compendium carries the depth, surfaces
carry the reading. The regular-human pass = the standing acceptance test for every future surface
wave.
