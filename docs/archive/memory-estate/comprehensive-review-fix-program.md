## confirming cycle, and every future review loop of this program)

close on the record alone; (b) matches a DEFERRED/deliberate ruling ⇒ re-test

re-discovery = a documentation-legibility finding in its own right; (c) novel ⇒
refuters unchanged. **Why:** the builder's memory is the largest blind-spot
source in a self-reviewing program; fresh eyes must see the artifact, not the
program's beliefs about it. **How to apply:** structure every review workflow as
S-cold → R-reconcile → refute → fix; never merge S and R.
