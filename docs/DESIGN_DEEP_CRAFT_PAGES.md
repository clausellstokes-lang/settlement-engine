## Foundation additions (Phase 0 — serial, before any page)
1. MATERIAL LAYER: tiled paper-grain (light + dim), ink-bite edge weighting in
   plate/ornament SVGs. Static assets only; budget-measured.
2. MOTION GRAMMAR (~12 named behaviors, foundation-defined, token-pinned,
   prefers-reduced-motion-safe): lay-down page arrival · unfold panel reveal ·
   rule self-draw on first paint · hover = ink-darken (never lift) · instrument
   press · slip-in toasts/notes · almanac page-turn · seal impress-once ·
   medallion ink-pulse · warm-dim modal ground · draft-settle for AI proposals ·
   tally-strike. No bounce, no spring, no generic fade.
3. HERO MOMENTS (bespoke, beyond-recipe): THE ARRIVAL (forge→dossier delivery) ·
   THE FIRST ADVANCE (almanac page-turn + medallion pulses + report slip) ·
   THE EXPORT CEREMONY (seal meets medallion on the cover) · THE ROAD (Welcome,
   tuned). Each specified before build; each instant under reduced-motion.
