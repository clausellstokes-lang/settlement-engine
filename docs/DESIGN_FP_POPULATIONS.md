## §1 THE LAWS THAT BIND EVERY WAVE

### 1a Constitutional (the engine's standing laws — non-negotiable; identical to
### the war volume's §1a and repeated because an implementer may hold only this file)
1. **Same-seed byte identity.** Same seed and inputs ⇒ byte-identical output,
   forever (THE PROMISE — constitutional).
2. **Dormancy.** Every wave ships DARK behind a virtual flag (absent from
   DEFAULT_SIMULATION_RULES); dark ⇒ byte-identical, golden-pinned BEFORE wiring.
3. **Seeded purity.** No Date.now, no Math.random, no locale reads, codepoint-sorted
   iteration on user data, no Math.pow/exp/log in engine paths (`w * u`, never
   `u ** (1/w)`). The demographic lanes already honor this with ZERO new rng
   streams (every dither is hash01 over stable keys — §2); new POP code holds
   that bar.

   only shrink. New engine code is a lazy leaf. Zero new any-casts.
5. **Receipts carry enforcement.** Every news entry carries `id` (the id-less drop
   class voids entries at BOTH normalizeEntry and the audit sink), full address
   chain, typed action, settlements BY NAME, recorded reason.

   DM truth; every new projection rides includeCovert/includeGroundTruth.
7. **Finite semantics.** Every vocabulary here is CLOSED and banded; no float leaks
   to a surface; counts speak only through QUANTITY_BANDS (the demographicsHerald
   idiom, graded the estate's model — §2).
