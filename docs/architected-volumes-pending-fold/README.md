here once its program has folded into `docs/DESIGN_FP_ARCH_*.md` on
`claude/composite-r4`. ⚠ **"DELETE a file here" applies to SNAPSHOTS ONLY.** An
instrument or a chair record in this directory has no canonical home on the build

⛔⛔ **THE DELETION IS THREE PARTS, NOT ONE, AND A `git rm` ALONE IS SILENTLY UNDONE.**
`scripts/refresh-archive.sh` copies each snapshot back unconditionally and then `git add`s
this whole directory, so the next refresh RECREATES the file and COMMITS it. Do all three:
(1) `git rm` the snapshot · (2) delete its `cp` line in `scripts/refresh-archive.sh` ·
(3) update the Contents row above. This is the same three-part shape the EPOCH RENAME
needed; it was written for the rename and not carried here until a fold-readiness recon
