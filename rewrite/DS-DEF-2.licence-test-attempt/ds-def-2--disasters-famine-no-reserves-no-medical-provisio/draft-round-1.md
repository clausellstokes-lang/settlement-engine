## 5. REFUSALS

**No variant is refused.** All three are written lawfully, in place, under their own vids and their
own angle tags; no variant is added, removed or merged; every face count rises from one to four.

**One law this pool cannot meet, recorded rather than faked — THE GRAMMAR COUNT.**
MOVE-GRAMMAR §2.1 requires min(k, 8) = **3** distinct level-1 grammars for a pool of three
variants. Filtering the level-1 set by this card's licensing fields leaves **two**: V1 (PRESENT,
the state key alone) and V3 (PRESENT → LACK, the state key plus a `none-exists` field, which both
flags are). V2 needs a structural-consequence field this card does not hold; V4 needs a
named-object field (the granary is a class word from a flag, not a named object); V5 needs the
institution TABLE, which this pool does not read and whose rows are absent here; V6 needs a state
field whose value is unresolved; V7 needs event provenance, which the block's PROVENANCE fence
denies; V8 needs a typed `not-held` RECORD field with provenance, which `SOURCE-UNRESOLVED` is not,
and whose sentence would need the record nouns W24 bars. **This draft therefore raises the census's
`grammars: 1` to 2 honestly and leaves the third unmet.** Inventing a member to satisfy the count
would be the worse fault. Recorded as a grammar-debt row for this pool and, since the four siblings
of `DISASTER_ROW_POOL` read the same shape, plausibly for the whole disaster lens.
