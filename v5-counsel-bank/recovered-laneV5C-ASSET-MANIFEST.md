## 3. PROCESSING PIPELINE (per asset: what happens after generation)

Order: **generate → spelling gate → owner glance-cull → cut/matte → crop-law crop →
tone-match receipts → retina export → manifest record (sha256 + byte ceiling + tone
stats + crop-line y + exact lettering text)**. Upscale (Higgsfield upscale) ONLY
where a usable crop lands under its 2x target — the 4K masters make this rare.

- **A1 SHAFT** (from `df26dabf`): crop the bottom half through the AXIS (crop line
  recorded); trim to the bar's aspect; alpha the below-rim parchment away. Targets:
  1440×38 @1x / 2880×76 @2x desktop; 390-wide mobile band from the same master.
  Tone stats recorded: L range of the label seat band, the lit-crest band, the rim.
- **A2 CARTOUCHE** (from `7b6e3ea7`): cut as a FULL-HEIGHT BAND PATCH of the bar
  (the band keeps its own wood — floating the marks alone loses the singe truth);
  feather both vertical seams and tone-match to A1 with a measured receipt
  (proposed: mean-L step across each seam < 0.02 at 1x; the exact threshold is the
  build's to measure and pin). If blending cannot clear the receipt, run R4.
- **A3/A4/R1/R2 VANES**: cut each pose as its own sprite — feather at full alpha
  PLUS its contact-shadow skirt as a separate multiply sub-layer (the sheets were
  generated on-shaft with true contact shadows; the skirt ships with the sprite,
  §2b of the spec). remove_background for the coarse cut, hand-refine the quill
  line and fray edge (fray must stay wispy, not haloed). Sprite boxes at 1x from
  the lane table (span × depth + fray allowance): Create ≈ 194×44 · Library ≈
  220×56 · Realm ≈ 178×48; flight variants ≤ 13px deep. Rest AND flight cut from
  the same sheet per feather (the two-pose-one-sheet discipline is what makes the
  crossfade morph-free).
- **A5 SEAL** (from `a396fc06`): ONE master, downscaled to every rung — 16px dimple,
  30px strike (@1x and @2x = 60px), 40px full device, plus hero sizes. No per-rung
  generation (spec §6 row-11 amendment). remove_background; keep the wax's own
  contact shadow as a skirt.
- **A6/A7 LABELS** (from `1fc18808` / `70dd2304`): matte the PAINT STROKES ONLY
  (luma/chroma key off the dark vane ground) — never the rectangular patch: a patch
  carries its own feather texture and will seam on a different feather photo
  (J-V5C-9). Word sprites ≈ 60–90px wide at 1x. ⚠ GATE before A7 is accepted as the
  active variant: overlay A6/A7 word-by-word; if glyph drift is visible at 1x, DERIVE
  the active variant from A6 by gold remap (#E9CD70-family) in post and keep
  `70dd2304` as the value reference only (J-V5C-5; report OQ6).
- **R3 TABS**: band patch like A2 (tabs keep their wood + singe); active/hover
  variants derived in post by alpha-matte gold remap of the ONE master (glyph
  stability); the drawn quill-line underline is composited, not generated.
- **All lettered assets — THE SPELLING GATE** (chair-run before the owner's glance):
  exact-string verification against the manifest text column — "SettlementForge"

  this gate.
