## §2 · THE CONTRACT

`deriveUndercityConnectivity(settlement, opts = {})` → the graph below, deterministic and pure.
**TOTAL:** `null`, `undefined`, `{}` and malformed inputs all yield a typed graph with empty lists;
nothing throws. **NO DRAW IS TAKEN AT ALL** — alone among the six cars this leaf has no seed-keyed
pick, so it defines no hash root and adds no entropy-census row.

| field | meaning |
|---|---|
| `character` | `spine` where the sanitation network exists (UC-1's rung ≥ culvert, read through UC-0's own `sanitationRungSeeds`), else `archipelago` (§311.9's law 4) |
| `spineDegree` | how many edges actually reach the spine — the honest companion to `character`, because a main with nothing attached is not a spine |
| `nodes[]` | every component row the four leaves published: `{ key, producer, kind, anchor, anchorKind, zone, posture, criminal, joints[], routeRank, severedBy }`. `anchorKind` is `INSTITUTION` \| `TERRAIN` \| `QUARTER` \| `FABRIC`, and only INSTITUTION rows join by anchor |
| `edges[]` | `{ class, cause, motive, from, to, fromAnchor, toAnchor, joint, posture, live, severedBy, payer, date, dateSource, sourceKind }` |
| `class` | `NATIVE` (free by construction — not dug, so no payer) · `ADJACENCY_BREACH` · `FUNDED_LINK` (§311.9.2(i)) |
| `cause` | `SAME_ANCHOR` (one building, one underside) · `DRAINED_QUARTER` (the spine reaches a quarter UC-1 drains) · `SHARED_QUARTER_WITH_MOTIVE` · `WORKS_EXTENSION` · `CONTRABAND_ROUTE` |
| `motive` | one per cause from the frozen `MOTIVE_BY_CAUSE` grammar — §311.9's law 2 made structural, so no edge exists without naming why it was worth digging |
| `joint` | the stricter side's own first published portal; on an equal-posture pair, the codepoint-first kind the two publish between them. ALWAYS a kind an endpoint published (one producer per join) |
| `posture` | the stricter side's place on the OPEN/GUARDED/SEALED gradient |
| `live` / `severedBy` | `false` + `FLOODED`/`SEALED` where a producer says the working receded. **The row persists** (§311.9's laws 5 and 6): severance is state, not deletion |
| `payer` | the canonical institution key that paid for a DUG act — the syndicate's for a criminal passage, the working's own owner for a works extension. `null` on a NATIVE edge, and a dug pair with no resolvable payer is NOT JOINED ("never an assumed corridor") |
| `date` / `dateSource` | `DATED_CALAMITY_REBUILD` with the ledger's own last year, `NO_DATED_RECORD` with `null`, or `NOT_A_DUG_ACT` on a NATIVE edge |
| `isolations[]` | `{ node, anchor, kind, posture, reason }` for every node no edge touches — `REFUSED` \| `SEVERED` \| `NO_PUBLISHED_JOINT` \| `UNREACHED`. The honesty contract as data |
| `refusals[]` | `{ reason, node, peer }` — `VAULT_REFUSAL` (§311.8.3, peer `null`) and `KEEPER_REFUSAL` (the sewer↔crypt join, peer the spine). A refusal is a DECISION and is written down |
| `sourceKind` | `DERIVED_V1`, frozen; changing any rule is a declared shift |

**`opts`** — `highWater`, `sewer`, `monotone`, `staticComponents`, `strata`, `undercity` each accept
