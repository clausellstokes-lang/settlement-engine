## A. The generation engine ("the Forge")

- **Settlement as data = three parts:** a frozen **config** (the intent it was born from), a frozen **dossier** (the generated expression — economy, people, institutions, history, hooks), and a **live state** (everything the passing weeks wrote). `[BUILT]` (source: docs/ONTOLOGY.md §1)
- **Three state strata, strictly ordered:** Frozen (never changes) → Persistent-Live (changes only via the tick engine or DM operations) → Derived (never stored, always recomputed, so it *cannot* drift). `[BUILT]` (source: docs/ONTOLOGY.md §2)
- **The pipeline is 22 registered steps** in a fixed, topologically-sorted order: resolveConfig → buildGenerationContext → resolveResources → resolveStress → resolveNeighbour → assembleInstitutions → subsumptionPass → cascadePass → isolationPass → stressConfirmPass → generateEconomy → generatePower → neighbourFactions → factionCorrelationPass → coherenceRepairPass → economyReconcilePass → powerEconomyReconcilePass → structuralValidationPass → generatePopulation → corruptionPass → generateNarratives → assembleSettlement. `[BUILT]` (source: I counted `registerStep` in `<tip>/src/generators/steps/`; matches ARCHITECTURE.md)
- **Tiers (the size ladder) are six:** thorp, hamlet, village, town, city, metropolis (`capital` is the pricing catalog's synonym for the top rung, displayed as "Metropolis"). Anonymous visitors are capped at Town. `[BUILT]` (source: `<tip>/src/config/tierFacts.js`)
- **Seeds and determinism.** Generation may draw randomness only from a seeded context; an unseeded draw *throws and halts*, in production too. Each step draws from its own **name-keyed** fork, so reordering steps does not change anyone's dice; loops iterate in codepoint order so no locale can bend a world. `[BUILT]` (source: docs/GENERATION.md §0.1)
- **Generation is structurally blind to the living world** — its only inputs are config, the custom-content snapshot, toggles, and an imported neighbour. This is what keeps mid-campaign regeneration replayable. `[BUILT]` (source: docs/GENERATION.md §0.2)
- **User edits are an overlay, never a mutation:** edits re-apply *after* the rolls and consume **zero** random draws, so an unedited settlement regenerates byte-identically and an edited one keeps its edits. `[BUILT]` (source: docs/GENERATION.md §0.3)
- **Golden master** (a settlement generated from a pinned seed, committed byte-for-byte; any output change reds the build): the manifest holds **525 config rows** at the tip. Re-recording is an owner-signed ceremony. `[BUILT]` (source: I counted `<tip>/tests/fixtures/generator-golden-master.json`)
- **Named subsystems, one line each** `[BUILT]` (sources: docs/GENERATION.md §2, docs/ONTOLOGY.md §1, `<tip>/src/generators/`): *institutions* (probability-weighted roster, then pruning ladders/subsumption/isolation; required, forced and custom institutions are contracts never silently deleted) · *economy* (solved as a bounded one-iteration loop against power and factions, with a versioned fingerprint proving the power structure consumed the final economy) · *food* (one authoritative writer; every other surface threads it) · *defense* · *services* · *trade goods and supply chains* · *resources* (terrain-legal, renewable vs nonrenewable, hand-classified) · *power and factions* (archetypes, power shares, legitimacy, succession) · *NPCs* (offices resolved against the power structure, traits, goals, secrets, plus an explicit per-NPC **corruption pass**) · *faith* (a **latent pantheon** baked identically for every paying tier and activated with zero draws, so tier never touches generation) · *history and timeline* · *stressors* (~15–20 typed pressures that counter and compound) · *plot hooks* (with escalation clocks and a closed theme vocabulary) · *narratives/prose*.
- **Cultures**: eleven naming cultures at researched register; a `culturalIdentity` is materialized once per run and persisted. `[BUILT]` (sources: docs/VISION_IDEALIZED_FINAL_PRODUCT.md, docs/GENERATION_CONTRACTS.md)
- **Custom content is first-class by the facet law**: a homebrew "Smugglers' Warren" gets the catalog's underground mechanics by right, because engines reason about machine-readable **facets**, never hardcoded names. `[BUILT]` (source: docs/GENERATION.md §5)
- **Deities: no premade pool.** Owner ruling 2026-07-21 removed the ~24-name pool and the seeding step; deities enter only via custom content, and the faith engine must be total over 0..MAX deities. `[BUILT]` (source: memory/deity-doctrine-no-premade-pool.md)
- **Canonization** builds a **frozen spatial digest** (distances, territories, routes, chokepoints from a provably deterministic pathfinder), deep-frozen so writes throw, and versioned so re-canonization is an explicit event. `[BUILT]` (source: docs/GENERATION.md §7)
- **End-state addition:** build by *speaking* — an intent compiler configures this same causal generator from a description, compares the result to the stated constraints and confesses deviations. "The AI configures the forge; it never fakes the forging." `[END-STATE INTENT]` (source: docs/VISION_IDEALIZED_FINAL_PRODUCT.md Layer 1)

## B. The living world (the simulation layer)

- **Tick** = one simulated week; year = 52 weeks on a 4-4-5 grid so month and season boundaries never drift. **Advance time** = N real kernel calls (a one-year advance is 52 real ticks), never a scaled shortcut. `[BUILT]` (sources: `<tip>/src/domain/worldPulse/worldState.js`, `advanceInterval.js`)
- **World pulse** = the pure one-week simulation kernel (`pulseKernel.js`, 2,931 lines) that composes the whole advance and emits an immutable receipt. A tick runs **9 declared ordered stages**: bootstrap → actor memory → condition aging → settlement clock → mover planes → candidate selection → permission and apply → consequence fold → finalize receipt. `[BUILT]` (source: `<tip>/src/domain/worldPulse/pulseStageManifest.js`)
- **Roughly twenty movers** run per week in documented order: pressures build → calamity → generous acts → foreign intervention → recovery arcs → settlements born and die → resources found and exhausted → migration → trade → smuggling → fleets → armies/sieges → war and peace reasons accumulate → treaties strain → blocs form and fracture → faiths contest → lies priced → rumors harden into beliefs → commitments deepen → tempo governor → docket routing → the world writes its own news. `[BUILT]` (source: docs/ONTOLOGY.md §4)
- **The epistemic architecture — reality exists three times over:** Truth, **Belief** (per observer, arrives late and fogged, wrong in both directions), and **Projection** (per audience, fail-closed). Wars begin in misjudgment. This is named the deepest idea in the design. `[BUILT]` (source: docs/ONTOLOGY.md §6)
- **Participation view** = the filtered roster handed to movers with off-stage people removed. **Off-stage / stasis** = a revocable shelf for a named NPC (journey, imprisoned, missing, sequestered) — "a shelf, not a grave", because the engine never resolves a named fate. `[BUILT]` (sources: `<tip>/src/domain/worldPulse/worldSnapshot.js`, `<tip>/src/domain/roads/state.js`)
- **Architecture law learned the hard way:** a read projection is never the write base. The tick landed the filtered `update.settlement` wholesale (`campaignPulseHelpers.js:197`), which erased shelved NPCs from the save. Cured on branch at `19c4cb853`; **not deployed**. `[IN FLIGHT]` (source: memory/hazard-the-participation-view-is-the-ticks-write-base…)
- **Realm** = the multi-settlement world: a regional graph of typed relationships (neutral, trade_partner, allied, patron, client, vassal, rival, cold_war, hostile, criminal_network) with 13 typed channels and a queued-impact timer. `[BUILT]` (source: docs/GEOPOLITICAL_WAR_LAYER.md §0 citing `regionalGraph.js`)
- **Built simulation families at the tip** (~443 files under `src/domain/worldPulse`, 34 under `src/domain/spatial`): war/siege/occupation/attrition/mobilization, coalitions, trade war and blockade, religion and religious contest, coups and faction competition, NPC agency, peace terms (~20 modules), the upswing/boom kernel, settlement politics, the narrative **tempo governor** (throttles spontaneous births, never causality), satellite and settlement lifecycle, hegemony read, distance-priced news, realm √N scaling, the Underways, the reframe layer. `[BUILT]` (sources: my directory counts at `<tip>`; docs/DESIGN_SIM_DEPTH_R2.md and siblings)
- **Intended end-state depth.** `docs/SIMULATION_TO_10.md` (2026-06-09) sets the yardstick: a 10/10 **cohesion engine** for DMs — explicitly *not* a hard quantitative economy sim. Its named root cause of every low score is "multiple parallel models of the same truth that drift apart"; its cure is "one canonical substrate, derived once, that every stage reads from and writes to." Per-subsystem scores then ranged 5–8. Four conserved ledgers (craft, welfare, transport, labor) remain **not started**. `[END-STATE INTENT]` (source: docs/SIMULATION_TO_10.md; the doc is listed HISTORICAL in docs/README.md)
- `docs/SIMULATION_LOGIC_AUDIT.md` (2026-07-01, self-labelled historical) prices cohesion at **7/10** and lists twelve intended-but-absent capabilities, the sharpest being **write-back from the world pulse into the dossier** (live corruption, ousting and faction capture never reach the static profile a DM reads). `[UNCERTAIN as current]` — preferred over TO_10 as newer, but both predate ~2.5 months of building.
- **The "FP" family is Foreign Policy, not Finished Product.** Thesis: foreign policy = four substances (war, trade, faith, populations) through one medium (information), in one grammar (diplomacy), driven by the interior (books and memory) — "after which foreign policy EMERGES and no seventh module is ever built." `docs/DESIGN_FP_ARCHITECTURE.md` compiles **thirteen programs / ~109 waves**, committing to **63 new virtual flags, ZERO new top-level worldState keys**, all new state as 14 conditionally-materialized sub-keys with exactly one writer each, every wave shipping **dark**. Nineteen of the 63 flags exist today. `[END-STATE INTENT]` (source: docs/DESIGN_FP_ARCHITECTURE.md; live count from `<tip>/src/domain/worldPulse/simulationRules.js`)
- Volume codes and status: **SP** spine `[BUILT]` · **GR** pact grammar, **IN** information, **TR** trade, **ES** espionage, **CW** cross-wires, **EP** advance-epoch `[IN FLIGHT]` · **WF** faith, **POP** populations, **INT** interior, **WY** wayfare, **HB** habit conditioning, **WC** war circulation, **LG** logistics, **CN** DM console, **MF** settlement-map fabric, **PG** pestilence `[END-STATE INTENT]`. `docs/architected-volumes-pending-fold/THE_FULL_ONTOLOGY.md` enumerates **192 systems across six tiers, 13 cross-domain loops, 16 promises, 12 boundaries**, with a status vocabulary that includes "BUILT, NOT REACHABLE" as a legitimate shipping state.
- **Order of the remaining program** (newest, 2026-09-20 ledger addendum 111): the **editor first**, then the **simulation architecture program** (recon → per-family architecture → the master ARCH-SIM fold → implementation "by trains", four lanes at a time). The owner's binding law: no implementation starts until every family's architecture is written. `[END-STATE INTENT]` (source: `docs/OWNER_DECISION_QUEUE.md` at `5815df21e`; memory/owner-directive-2026-09-15-prioritise-the-simulation…)
- **The constitutional amendment that governs replay** (owner, 2026-08-05): the promise narrowed from "a seed is a world" to **"a seed is a STARTING world, forever; a lived history, once lived, forever."** Every user-facing advance and every reroll mints fresh entropy (recorded as a nonce) so the same beloved starting world can tell a different plausible future; internal byte-exact replay is retained from the recorded nonces. **This supersedes the unqualified "same seed, same world" wording in the 2026-07 docs**, and I prefer it as the newest owner-ratified statement. `[IN FLIGHT]` (source: memory/the-promise-ratified.md + advance-epoch-living-futures-directive.md; EP flag present in `simulationRules.js`)

## C. The editing layer (Edit Mode and the Decree Registry)

- **The intent** (owner design, 2026-09-19): a saved settlement gets an **Edit Mode**; every editable card carries a pencil and every extensible section a plus; clicking opens a generated modal whose values come from **typed pools** (the finite-semantics law as an interface). Each save enters an ordered **decree registry** at the dossier's foot; leaving edit mode and advancing time applies the entries in order. `[END-STATE INTENT]` (source: docs/ARCH_EDIT_MODE_AND_DECREES.md; memory/design-2026-09-19-edit-mode-…)
- **Decree** = a queued DM operation with status (pending/applied/withdrawn) and provenance (dm/guard/surveyor), applied at the head of the tick as a first-class cause with a chronicle line. `[END-STATE INTENT]`
- **Corrections vs events, as the owner finally ruled:** the settlement's **state** decides, not the field — a draft takes plain edits applying now; a **canonized** town turns every pool-valued edit into an EVENT at the next advance. Annotations and names (free / free-cascade) still apply on Save. `[END-STATE INTENT]` (source: memory addendum ~20:0x and §934.52)
- **Guards are suggestive, never refusing.** A guard says "X must happen before Y" and offers *fulfil it for me* / *I'll do it* / *proceed*; an override is chronicled with the table's hand as its cause. The engine **folds**: each pending entry is judged against the world with every earlier entry applied. `[END-STATE INTENT]` (source: docs/ARCH_EDIT_MODE_AND_DECREES.md §5)
- **Edit at the source, never at the derivation.** Three kinds of fact: **seed-level** (the wizard's dials), **root** (a writer that reads no other world fact — NPC name/role, institution name/class, faction category, power seat holder), and **derived** (economy, supply chains, defense, food, history — never editable; the card shows provenance instead of a pencil). A walker refuses a declaration for a derived field. `[END-STATE INTENT]` (source: docs/ARCH_EDIT_MODE_AND_DECREES.md §9; memory §934.44)
- **Re-derivation is one engine, not a re-roll.** `rederive(record, config′, layer)` re-runs the derivation with every registered chooser's output **pinned** from the record; a root edit is one pin released; a world-fact change (terrain, culture, resources) re-derives without re-rolling. Fresh generation with no pins must equal the golden byte-for-byte. `[END-STATE INTENT]` (source: docs/ARCH_EDIT_MODE_AND_DECREES.md §1)
- **Three executed recons proved the engine as first designed does not run.** Record-built pins reproduced a settlement 6/63; only a pin consulted *inside* `enrichNpcCoherence` reproduced 63/63; a terrain change throws the power-economy freshness assert; 52/56 joins among held facts are on display names and institutions have no rename cascade. The ruled cure is a three-way merge `record + (R1 − R0)` whose unit is a **declared consistency group** (the smallest object that closes an invariant), guarded at runtime by `recordInvariants`, applied **one edit at a time like a decree with no batch path**, with record keys classed by path (HELD / WORLD / CONSTANT / READING / MIRROR / RECEIPT / HISTORY / AUTHORED). The honesty cost is accepted: the delta card shows three values — before, now, and what the edit alone accounts for. `[IN FLIGHT]` (source: memory §934.47 addenda 18 and design §22.2)
- **Stable identity** is a prerequisite being built: `npc:<n>` / `inst:<n>` / `fac:<n>` minted from the step's stream, because today NPC ids are positional and institutions are keyed by name. `[IN FLIGHT]`
- **Phantoms** = DM-named off-stage counterparties minted from a seed as minimal hidden save records, so a theatrical war or trade needs no realm. **The phantom consequence rule:** an act against a phantom yields the home procedures plus a chronicle line and *nothing else* — never world state. `[END-STATE INTENT]`
- **Edits do not travel:** `dmLayer` and `decrees` live only in the owner's save; forks, imports, the gallery and exports carry the seed's world alone, proved by a runtime travel test plus three mirrored denylists. `[END-STATE INTENT]`
- **Build shape:** a packet train of **nineteen packets in five waves** (`docs/implementation/charters/EDIT-MODE-TRAIN.md`), gated behind `TIER_GATE.premium.editMode`. Only `src/domain/edit/recordRegister.js` exists in the clean tree. `[IN FLIGHT]`

## D. Prose and language

- **State prose** = a sentence explaining a standing condition, written as the settlement explaining itself; **causal prose** explains why one domain moved another. A **receipt pool** = a named bucket of 3–5 angle-distinct authored variants keyed to one typed state combination. The dossier-state corpus is 5,520 lines, 59 blocks, **2,149 authored variants, coverage 77/77 surfaces**; eleven sibling pool files cover war, trade, faith, populations, interior, information, couplings, grammar. `[BUILT]` (source: docs/content/RECEIPT_POOLS_DOSSIER_STATE.md)
- The corpus **projects** into six generated code leaves (31,932 lines); a **projection contract** test pins Markdown corpus → generated leaf. `[BUILT]` (source: `<tip>/src/data/dossierStateProse/`)
- **The prose kernel** (`stateProseKernel.js`, pure, no imports, no clock, no RNG) enforces **anchored liveness** (a variant renders only if every slot has a real fill; otherwise nothing renders — never a stub), **fail-closed audience** (an unrecognised audience is treated as the player's), and an avalanche-mixed hash draw. `[BUILT]`
- **Two unrelated "weaves"**: `weaveBlock.js` joins drawn sentences into one paragraph and stands repeated names down to the tier noun, adding not one authored word; `DESIGN_COHESION_WEAVE.md` is the mechanical cross-cutting modulation layer. A genuine vocabulary collision. `[BUILT]`
- **Voice** is one archivist's, machine-enforced: zero em dashes, zero exclamation points, one idea per sentence, no interface-speak; `voiceMechanics.test.js` runs five tiers (hard zero on copy registries, shrink-only ratchets on data/domain literals, a JSX-AST tier) and `proseNumerics.test.js` forbids engine float notation in reader prose. `[BUILT]`
- **Finite semantics** (owner law): players have unlimited freedom, the world's memory of it is finite. Every effect touching the engine is a typed record from a closed vocabulary with bounded magnitude. Free text has exactly three legal roles — the DM's verbatim words on a receipt, fuel for AI flavour, and input UX the AI buckets into *proposed* typed records a human must confirm. `[END-STATE INTENT / owner law]` (source: memory/finite-semantics-law.md)
- **AI as clerk, never writer** is structural, not prompt-level. Four substrate modules: `aiCharter.js` (the teaching block, derived from the same builders the schema walls trust), `aiOutputSchema.js` (the same vocabulary as a provider `input_schema`, so an unregistered bucket is *unemittable*), `aiGrounding.js` (the simulator's own facts plus explicit `forbidden`/`lockedEntities`), `aiOverlayVerifier.js` (runtime canon guard typing six violation classes). All sort before printing so cached prompt prefixes hit. `[BUILT]` (source: `<tip>/src/domain/`)
- **BYOK** = the user's own provider key, stored encrypted server-side, decrypted per request in the edge function, never logged or returned. A vault failure **fails closed** as a typed refusal rather than silently falling back to the house key. `[BUILT]`
- **The Scribe** is the end-state AI prose writer: when a dossier is opened, a model reads a **town card** (this town's exact facts), writes every prose unit, is refuted, and survivors persist as `settlement.prose` — an inert artefact **no mechanic reads**, written once per epoch keyed `(seed, advanceSeq, engineVersion, scribeVersion)`. Truth is guarded in two tiers: tier 0 pure code (mechanical bars, prose-leak classes, move grammar, a referent scan), tier 1 a same-model checklist against the card's finite denial list. Any refused unit falls back to the hand corpus. `[END-STATE INTENT]`
- **The Scribe is not in the shipped tree.** Docs say built-and-dark through wave W5b on preserve refs; I confirmed no `scribeBrief.js` / `townCard.js` / `refuteUnit.js` / `supabase/functions/scribe-render` at the tip. Simulated runs measured 84–89% unit survival with ~0.5–0.7% of surviving lines still contradicting something. Cost contradiction on the record: the design said "cents per settlement"; the later tier proposal measured **$0.73–$1.32 per render** against a 5-credit retail of $0.65–$1.00, and found a billing defect charging per tab (35–50 credits for an advertised 5). Sixteen Scribe decisions are owner-gated and open — including whether finite semantics forbids AI-authored dossier prose at all. `[IN FLIGHT]`

## E. Persistence and platform

- **Saves** go through one service with two interchangeable backends: Supabase Postgres when configured, browser `localStorage` otherwise, behind the same async API. Payloads pass an **admission parser** classifying every envelope current/migrated/rejected. `SCHEMA_VERSION` is 1; `settlementMigrations.js` upgrades old saves. `[BUILT]` (source: `<tip>/src/lib/saves.js`, `saveAdmission.js`)
- **Offline** means local storage plus a durable owner-scoped **outbox** that replays queued writes; there is no service worker or installable app shell. `[BUILT]`
- **203 SQL migrations**; production applied head is 200, so 201–203 are written and undeployed, surfaced deliberately by `validate:migration-head`. 58 migrations mention RLS, 45 create policies; RLS is the security spine. Rollback coverage is partial (7 `.down.sql`). `[IN FLIGHT]` (source: `<tip>/supabase/`)
- **32 Deno edge functions** plus a built `_shared` bundle: AI (`generate-narrative`, `ai-analyst`, `generate-chronicle`, `surveyor-*`, `interview`, `parley`), money (`stripe-webhook`, `create-checkout`, `payment-refund-worker`, `verify-*`), ops (`health`, `analytics-export`, crons, `operator-message-worker`). `[BUILT]` (my count at `<tip>`)
- **Tiers:** `wanderer` (free, 3 saves) → `cartographer` (unlimited saves) → `surveyor` (the AI stages) → `founder` (30 invite-only chairs, never sold), plus a $2.99 single-dossier purchase. **The engine is never tier-gated** — every tier runs the same simulation; only saves, exports, custom content and AI are gated. Each ladder row names the code symbol that enforces it, walker-tested so advertised paywalls cannot drift from enforced ones. `[BUILT]` (source: `<tip>/src/config/entitlementLadder.js`, `tierFacts.js`)
- **Sharing:** a fail-closed player-safe allowlist projection plus a DM-variant gallery projection that still strips AI prose, seeds and the latent pantheon; the client projection mirrors an authoritative server sanitizer, and migration 203 exists because that mirror went stale three times. `[BUILT]` (source: `<tip>/src/domain/display/publicSafe.js`, migration 203)
- **Import** of an existing campaign runs `ingested → reconciling → previewed → applying → applied` on the same previewable, idempotent command plane as manual edits; imported prose never silently becomes mechanical truth. `[BUILT]` for the structured-export vertical, `[END-STATE INTENT]` for natural-language and third-party formats.
- **Export as ground truth:** a whole realm exports as one versioned, deterministic JSON portrait in DM and player variants, consumed by a **Foundry VTT module** and a local **read-only MCP "Truth Server"** whose four tools cite the export, variant, settlement and tick they answered from and have no write or network path. `[BUILT]` (source: `<tip>/mcp-server/`, `foundry-module/`)
- **The completed write path** (the end state): manual controls and Surveyor compile to the same **command drafts** → an application command executor (admit, resolve a legal spec, authorize owner/target, validate expected revision and preview freshness, claim command identity, run the pure domain op, persist, finalize a **receipt**) → owner-scoped Postgres with compare-and-set → read models. Migration is vertical, one command family at a time; a generic dual-authority wrapper is explicitly not completion. `[IN FLIGHT]` (source: docs/PRODUCT_COMPLETION_ARCHITECTURE.md §2, §4)
- **Deploy** is fail-closed: Vercel's push build is always skipped, and two independent gated paths ship only when every CI gate is green on master. The dashboard half (branch protection, tokens) is still operator work. `[IN FLIGHT]`

- **Phone floors** are a census of guard tests (tap-target floors, chrome floors, dossier prose floors, a nav-order walker), not a convention. `[BUILT]`
- **Performance budgets:** the **first-paint ratchet** is constitutional — the built entry chunk's static closure must stay under a monotone owner-gated ceiling (`CLOSURE_BUDGET_BYTES = 1,048,000` raw, 337,000 gzip, 283,000 brotli at the tip). The engine is a ~514 kB lazy chunk fetched on first Generate, never at first paint. ## G. The quality estate — each instrument and the failure it prevents

- **The gate** (`npm run check`) is a 17-step `&&` chain and the single landing authority: 11 validators → 2 type ratchets → lint → test ratchet → build → `verify:dist`. `[BUILT]`
- **Ratchet** (only-shrink census): a frozen per-item ceiling that may fall but never rise. *Prevents* a pre-existing backlog making a gate permanently red — which once blinded lint, test, build and dist for four days and ~368 commits. Three live: per-file typecheck, per-**test** failures, first-paint bytes. `[BUILT]`
- **Walker** (129 files): a test that enumerates the source tree and compares it to a frozen inventory. *Prevents* a new file or case joining a family without the wiring that family requires. A separate law keeps walkers out of the test ratchet: a failing test is debt, a failing walker is a **disabled guard**. `[BUILT]`
- **Lighting census**: five frozen figures measuring whether declared subsystem evidence actually arrived. *Prevents* a document claiming three waves landed when no artifact proves it. - **Goldens and the golden-record door**: a **door** is a single sanctioned exception route replacing scattered ad-hoc ones. ## H. Tuning

- A **band** is a range on an *observed metric during the soak*, not a value for a constant (dial `CHALLENGE_RATE = 0.05`; band = 1.5–4.0 court successions per faction per decade). Units are a closed vocabulary of 14; a unit-less table cannot be signed. `[BUILT]`

## WHAT THE FINISHED SYSTEM IS, IN ONE PARAGRAPH (engineering view)

SettlementForge, finished, is a deterministic world engine with a web application wrapped around it. At its core sits a pure, headless, seeded generator — no clock, no network, no framework — that turns a short configuration into a fully internally-argued settlement in twenty-two ordered steps, each step drawing from its own named branch of one seeded random stream and leaving a receipt for every decision it made. That output is then frozen forever, and everything that happens afterwards is written as a thin overlay of change-notes on top of it, so the world can move without the record of its birth ever being corrupted. A second pure engine, the world pulse, advances that world one real simulated week at a time through nine declared stages and about twenty independent movers — war, trade, migration, faith, rumour, politics, disaster, recovery — each of which can be switched off and contributes exactly nothing when it is. The engine's distinguishing property is that it models three separate realities: what is true, what each court *believes* (late, fogged, and wrong in both directions), and what each audience is permitted to see — and it never resolves the fate of a named person, only the state of institutions, places and populations. Around that core the finished system puts one narrow write path — every change by hand, by AI, or by the DM's decree compiles into the same typed, validated, previewable, receipted, reversible operation, applied through a command executor against owner-scoped Postgres with compare-and-set — and one wide read path of derived-only projections: a ~26-tab dossier, a matching 23-chapter PDF, a map, a chronicle, an exportable world that a Foundry module and a local read-only MCP server can serve as ground truth to any other AI. The AI layer is architecturally a clerk: it can propose typed operations and write inert prose that no mechanic reads, and the schema itself makes an unregistered intent unemittable. Holding all of it honest is a test estate roughly the size of the product, built less around "does this feature work" than around "can this class of failure still happen": only-shrinking ratchets instead of boolean gates, walkers that enumerate the source tree against frozen inventories, an observed-shape register that runs the real producers to find code reading keys nothing writes, signed shift records behind a single door before any golden may move, and a certification manifest that is deliberately empty until a hundred-year soak actually writes a band. What remains to reach that end state is not mainly new features: it is the editing layer and its re-derivation engine, the thirteen foreign-policy programs that bring trade, faith, populations, information, interior and diplomacy to the grade war already has, the vertical migration of the remaining mutation families onto the durable command spine, the deployment of the migration train, the long soaks that would let the certification manifest and the tuning register be signed, and the uncoached user evidence that no internal gate can produce.
