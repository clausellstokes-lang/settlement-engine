Today a settlement's creed can be evicted from the light and **nothing records when**. Executed at
this base: `git grep -c suppressedAtTick 9d851fae -- src` returns **zero hits — the field does not
exist in code in any spelling** (WF-S001, re-executed). Three sites write `suppressed: true`, and the


So a settlement that loses four creeds forgets the one whose ref happens to sort last — **an
underivable obituary**, which is the volume's own finding (`DESIGN_FP_FAITH.md`, the CORRECTED
extinction beat).

WF-1b-i makes suppression **stamped and ordered**: every suppression write goes through ONE helper
that records `suppressedAtTick` when the fold hands it a tick, and — lit — the prune keeps the
**newest-suppressed** and drops the **longest-dormant** first, so the creed the world forgets is the
creed longest gone from the light, derivable link by link. Dark, the codepoint order is unchanged and
the serialized bytes are identical.
