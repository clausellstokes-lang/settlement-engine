HOW TO COMPLETE THIS FILE
-------------------------

Replace this section with the verbatim body of the SIL Open Font License,
Version 1.1, retrieved from the canonical source named above, and delete the
incomplete marker at the top of this file.

The body was not written here by the lane that created the file: no copy of the
OFL text exists anywhere in this repository, in its installed packages, or in
the font binaries (every face has an empty name ID 13, the License Description
field), and that lane had no network access. Reproducing a licence from memory
risks shipping terms that differ from the real ones, which is worse than
shipping none, so the gap was left visible and reported instead.

When the body lands, update the font rows in THIRD-PARTY-NOTICES.md and in
public/third-party-notices.html to match.
