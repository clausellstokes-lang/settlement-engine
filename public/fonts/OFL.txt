SIL OPEN FONT LICENSE NOTICE - the Lora and Nunito families
===========================================================

This file carries the copyright notices and Reserved Font Name declarations for
the two font families served from this origin, followed by the verbatim body of
the licence they are offered under. The SIL Open Font License asks that its text
accompany the fonts; that text is reproduced in full below, so this one file
satisfies the request on its own.

The fonts themselves are unmodified. Neither family is renamed, and no Reserved
Font Name is used on a derivative.

WHERE THE TEXT BELOW COMES FROM
-------------------------------

Each copyright line below was read out of the corresponding TTF name table
(name ID 0) in this repository. All four faces of each family carry an identical
notice.

The Nunito faces declare the licence URL in their own metadata (name ID 14):
https://scripts.sil.org/OFL

The Lora faces carry the copyright with the Reserved Font Name wording but
declare no licence URL field; the canonical text is the same document, and it is
the one reproduced here.

The licence body is reproduced from the OFL.txt that Google Fonts distributes
with these two families. The copy shipped with Lora and the copy shipped with
Nunito are byte-identical below their FAQ-pointer line; the two differ only in
the scheme of that pointer, and the https form is the one kept here. No part of
the text below was written from memory.
