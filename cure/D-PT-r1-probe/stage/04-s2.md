### 2.2 The engagement (one shape for every party family)

```
Engagement = {
  id,                 // 'eng.' + FNV-1a(kind, actorKey, sourceKey, mintTick) — zero rng, never `now`
  kind,               // a PARTY_ENGAGEMENT_KINDS member (§13)
  actor: actorRef,    // { kind: 'settlement', id } (a court) · { kind: 'person', id: 'wnpc_…' } (a paragon, a renowned voice — persons lit)
  officer?,           // RN's actingOfficer key and office (the WATCH, the BENCH …) — who makes the act; a bound paragon carrying its employer's act
  anchorId,           // the docket's real settlement (§13's anchor rule)
  where,              // { kind: 'settlement' | 'road' | 'country', ids } — the card's place the map can name (§13, ENC-HL-13)
  need?,              // { stressorId } · { siege: { targetId } } · { warKey } · { callSource } (no clock) · { deedId } (a grievance) · { engagementId } (an escalation's parent)
  offer?,             // OFFER_KINDS member, for party_offer
  visitPurpose?,      // to_meet · to_warn · to_challenge, for party_visit
  state,              // seeking · awaiting · pledged
  since, mintTick,
  pursuit: { budgetWeeks, spentWeeks },        // pursuitClock (PT10)
  patience?: { budgetWeeks, spentWeeks },      // patienceClock, only for a pledge whose need has no clock
  clock?: { deadlineTick?, threshold? },       // the need's clock, set at yes (§8.2)
  earliestArrivalTick?,                        // the fault read (§8.4)
  reachedTick?,                                // the first tick the party's whereabouts named the need's settlement while pledged (§8.6)
  step?,              // the escalation rung (summons → warrant → bounty → hunted)
  answer?: { word: 'yes'|'later'|'no', deedId, tick, laterTick? },
  causedBy            // the deed, call, grievance, crossing or parent engagement that started it (requirement 20)
}
```
