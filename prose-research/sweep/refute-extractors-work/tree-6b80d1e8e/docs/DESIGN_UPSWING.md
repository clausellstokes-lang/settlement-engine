## 0. THE CONSTITUTION (owner law, binding every stage)
1. **UNIFICATION** — no boom machinery separate from bust machinery. The engine's variables
   (prosperity, population, trade throughput, institutions, legitimacy, conditions) were built
   read-write but the write traffic ran mostly downward (the stasis finding). W-UPSWING
   completes the SIGN: booms and golden ages are emergent READOUTS over the same ledger, with
   hysteresis — never a declared state the engine then enforces.
2. **CONSERVATION** — every upswing has a typed SOURCE and the source is DEBITED: ally aid
   debits the giver's surplus (the E1 obligations/credit ledger matures), population inflow is
   someone's outflow (the M4 migration ledger already conserves Σarrivals+Σdeaths=Σdepartures),
   trade growth requires the route and partner to exist (M6d tallies), extraction debits the
   conquered (conquestFeeds/tribute), discovery draws down a bounded latent pool
   (W-DISCOVERY, its own design). Receipts name source and limit, always.
3. **LIMITS ARE FIRST-CLASS** — (a) resource carrying capacity (the digest's endowment; reads
   go through W-DISCOVERY's effective-endowment chokepoint once it lands); (b) ally aid =
   INTENT × CAPACITY (generosityEV computes both — consume it, never reimplement); (c) the
   extraction-to-benefit CONVERSION: an empire's conquest upswing is scaled DOWN by its own
   corruption (the corruption web is the leak in the pipe — foreignGrip/compromised seats
   reduce what citizens see; the read exists, this wave couples it); (d) ABSORPTION — the one
   genuinely new bound: a settlement integrates at most a capped inflow of aid/investment/
   people per tick (a small tuning table, deferral-visible when saturated).
4. **REGIONAL-OR-LOCAL** — regional character emerges from SHARED SOURCES (a reopened trade
   artery, a peace dividend), never a new scope object: correlated local upswings, legible as
   such in the chronicle.
5. **MOTIVE INTEGRATION** — "an empire seeks to conquer to improve their upswings; an ally
   invests and that grants an upswing." Conquest/strategy EV gains a bounded
   extraction-upswing term (what this conquest buys, after occupation burden and the
   conqueror's own conversion leak); the E1 instruments are the investment verbs whose upside
   loop this wave closes.

## 1. STAGE 0 — THE CALAMITY BUCKET (owner ruling: "the flavor is for the DM; the effects we
## are going to bucket into one")
RECON VERDICT (CONFIRMED): M11b already IS the bucket — K-selection, subsumption fates,
death/exodus fractions, the M2 sever, exodus routing, tier demotion, and the legitimacy
condition are ALL type-blind; "flood" exists only as a terrain→label prose table
(DISASTER_TYPE_BY_TERRAIN → DISASTER_TITLE → typeLabel) stamped AFTER the roll, plus comments.
Drought is NOT calamity (it is the separate seasons-variance system and stays there). The
stage therefore ships four closures, no mechanical rework:
- **FLAVOR DEMOTION**: the stamp's terrain-derived label becomes an explicit cosmetic
  `flavorHint` (same persisted key `type` — no save-shape change; existing stamps read
  unchanged). Engine prose stops ASSERTING a disaster kind: titles/news/receipts speak the
  bucket ("the Great Calamity of {year}", "disaster struck") with the hint available to
  display as a SUGGESTION the DM may override; composer/dossier flavor freetext is the DM's
  slot. This also FIXES the recon-found live mismatch (voice lines picked by category, not
  type — a quake could draw "the waters have gone down").
- **EXPOSURE LOADING (JUDGMENT, vetoable — the §H conformance)**: hazard is today uniform
  1/(15·N) regardless of situation. Add a mild, bounded exposure multiplier (0.75×–1.5×:
  terrain risk + prior-calamity dwell), NORMALIZED so the realm-wide expected cadence
  (one strike per ~15 years) is UNCHANGED — exposure redistributes risk, never raises the
  total. Receipts say "exposed geography," never a disaster name.
- **FORCE_CALAMITY** (counterpart criterion): registrable-shape verb — severity dial (bands
  scaling K and the death/exodus draws WITHIN the existing bounds: DEATH_MAX 0.14 /
  EXODUS_MAX 0.26 stay the walls), optional flavor freetext (cosmetic only), applied through
  the SAME kernel path as an organic strike (force ≡ organic by construction). Manifest
  registration itself rides the W-COMPOSER-2 lift.
- **SURFACING**: calamityHistory is persisted but read by nothing in the UI — the dossier
  gains its calamity ledger (display-lazy), which stage 1's reconstruction then references
  ("rebuilt in the year …").
**THE ONE-TIME SHIFT (documented, owner-ruling-caused, never silent):** prose neutralization
moves lit-path news/prose goldens once; exposure loading redistributes same-seed strike
locations on lit paths once (dark worlds byte-identical throughout — calamity is
ladder-gated). Both land in ONE re-derivation batch with the cause recorded in the ledger.

## 2. STAGES 1–3 — THE ARCS (Part B, constitutionalized)
**B1 RECONSTRUCTION** (after a calamity stamp or a siege/occupation clearing): the
positive-polarity `reconstruction` condition via the existing condition lifecycle; progress =
f(prosperity band, builder roster, inbound ally credit, peace dwell), REGRESSING on new
shocks. CONSERVATION AMENDMENTS: ally-credit acceleration MATURES the obligation (the ledger
debit — aid consumed is aid spent), internal progress debits the surplus read, and every
milestone receipt names its source mix. Completion: the permanent history beat, the
legitimacy dividend, the institution UPGRADE drawn UP the same lattice calamity demotes down
(demote table read in reverse; the dedup reused), and — no free candy — the reconstruction
SKIM (funds flowing × low conscience feeds corruption pressure: the rebuild race can birth
the next corruption arc).
**B2 BOOM → BUST**: sustained M6d throughput + entrepôt centrality + surplus dwell mint
`boom` (founding-cadence bonus, migration pull unchanged — M4 already reads prosperity,
prosperity drift up) with hysteresis; the condition RECORDS ITS OWN FRAGILE EDGES (the M2
<2-independent-sources flag) so a severance/embattlement — or a W-DISCOVERY resource removal
— flips boom to `bust` with the receipt naming the dead artery. SOURCE TYPING (constitution):
the boom receipt carries its source set {trade artery ids, extraction, aid, discovery};
regional booms are the shared-source correlation made legible.
**B3 FLOURISHING**: prosperity + legitimacy + peace-dwell high N ticks (a new peace-dwell
counter — the recon confirmed none exists; derive from war-front reads) → the bounded
cultural condition: tolerance drift, temple/academy founding bias, piety warmth, chronicle
beat. war_exhaustion's mirror; NO power snowball (no military/economic multiplier; capped
duration + cooldown — as frozen).
**STAGE 4 — MOTIVE INTEGRATION**: the bounded extraction-upswing EV term (constitution §0.5)
into conquest/strategy scoring, 0-when-dark, warSentimentAdj-idiom; and the corruption
conversion-leak coupling scaling extraction benefits.
