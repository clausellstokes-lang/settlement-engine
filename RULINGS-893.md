## 1. ⭐ CS-9 — an account import of a user's OWN export is a RESTORE PATH, not an authoring wall
**RULED: RESTORE.** The import hydrates, binds and exports the pack, marking any entry whose characters the renderer cannot draw as `charset_legacy` and surfacing it for repair. It does **not** refuse the pack. The wall stays ABSOLUTE on the AUTHORING path, which is what it was built for.

**Ground.** The wall exists to stop NEW content entering with undrawable characters. A restore is not new content: it is the user re-hydrating what this product already accepted and already handed them. Refusing it destroys data the user owns, in a format only this product writes, with no external editor to repair it — an unrecoverable state manufactured by a guard meant to prevent one. The asymmetry is decisive: a legacy entry that renders imperfectly is visible and fixable; a pack that will not load is neither.

**Veto shape.** Rule it an authoring wall and CHARSET Car 2 builds a flat refusal instead of the split; the cost is a paying user whose own export will not open. **Releases:** CHARSET Car 2 (stage B) and the charset half of L-DOORS (stage E).
