# THE MAP PROGRAM'S REPLY ON THE HIDDEN WAYS — as the owner relayed it (2026-10-18 ~23:0x EDT; the map side's words, pasted by the owner: "to clarify, this is what we landed on")

Here is how it would work, start to finish, with no jargon.
Two programs share the world. One runs its life: towns, trade, armies, gangs, who knows what. The other draws the land: hills, rivers, roads, paths. They talk through a message window. The life program sends facts like "town A now knows this path" or "this path is now a trail". The map program sends geography like "here is every road and every path, and here is how hard each stretch is to travel". Neither invents the other's facts.

At the birth of a world
1. The map builds the land first: terrain, rivers, forests.
2. The life program places the towns and decides which towns should be connected. The map then draws each road, picking the best line across the terrain.
3. The map also draws every plausible footpath through the rough country, forest, hills, marsh, mountains, but marks them all "wild". Nobody knows them and nobody uses them yet. On open plain there are none.

During play
* A gang, a smuggler or a patrol needs to cross country without being seen. The life program sends it along a wild path. Each use counts. After enough use the life program raises the path's status: wild, then a way, then a trail. The map draws whatever the current status is, in the right style.
* Knowledge is separate from status. A town only sees a path on its map once the life program says it knows it, because a patrol caught someone on it, a spy mapped it, a warden holds the office, or the game master revealed it. Knowledge fades if nobody uses or watches the path, and a town can know just the first stretch "as far as the ford".
* Where a path meets a road is a junction. That is where ambushes happen and where patrols set their checkpoints. Junctions have names, so an event can say "at the fork below the ford".

How a road is born organically
* A trail that a town adopts rises to a track. If use keeps growing, the life program charters a real road along it. The map draws the road between the trail's two junctions, and from then on it is a road like any other.
* With your rule, that road can start or end at a junction on another road. So a village's branch road forks off the trunk road where the detour is small, instead of running its own road all the way to the city.

How a road dies
Roads that nobody uses are downgraded step by step, road to track to trail to hidden. They are never erased. A hidden road is a ghost only the game master sees, and if use returns it comes back.

The net effect: the road network looks like real countryside, trunk roads with branches and old ways, and it changes because of what the people in the world actually do.
