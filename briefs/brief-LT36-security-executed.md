Ship the baseline in the SAME commit as the rule — this is the ordering backend.3 itself warns about ('Step 3 depends on Steps 1-2 being done or it fails red immediately'), and the estate has the pattern already in scripts/.raw-button-baseline.json.

Tune the detector to the call-site shapes that actually carry a value — template interpolation of a PII-named expression, or a bare identifier argument matching the token list — and prove both directions with negative controls, or the baseline swells with false positives and the rule loses its teeth.
