## 6. Exact contracts

### 6.1 Inputs and outputs

```js
/** The closure kinds, and the flag each one stamps. A closed set. */
export const REMNANT_CLOSURE_FLAG = Object.freeze({
  economy: '_worldPulseEconomyClosed',
  moral: '_worldPulseMorallyAbolished',
});

/**
 * @param {CalInstitution} inst
 * @param {{ reason: string, fate: string, closure: 'economy'|'moral', outcomeId?: string|null }} opts
 *   reason    — what the roster shows as `remnantReason`. REQUIRED.
 *   fate      — what the roster shows as `worldPulseFate`. REQUIRED.
 *   closure   — WHICH closure this is. REQUIRED, and a member of REMNANT_CLOSURE_FLAG.
 *   outcomeId — emitted as `closedByWorldPulseOutcomeId` IN PLACE when present;
 *               OMITTED entirely when absent (the magic-regime site writes no id key,
 *               and an emitted `null` would be a byte the site never wrote).
 * @returns {CalInstitution} a NEW record; `inst` is never mutated
 */
export function remnantInstitution(inst, { reason, fate, closure, outcomeId }) { … }
```

Return shape, in exactly this key order:

```js
{ ...inst, status: 'remnant', _worldPulseInactive: true, [REMNANT_CLOSURE_FLAG[closure]]: true,
  worldPulseFate: fate,
  ...(outcomeId === undefined ? {} : { closedByWorldPulseOutcomeId: outcomeId }),
  remnantReason: reason }
```

⛔ **`closure` IS REQUIRED AND THAT IS THE WHOLE POINT.** A defaulted `'economy'` would stamp
`_worldPulseEconomyClosed` on a moral abolition, which `institutionStatusModel.js:334` reads as a
SHELL and `:319-321` declares it must never be. The three-of-four byte-identity result below is
what a defaulted flag destroys.

Absence rules: absent/empty/non-string `reason` → `TypeError`; same for `fate`; `closure` outside
the closed set → `TypeError` naming the members; `outcomeId` absent → the key is omitted (never
`null`). All four refusals are proved in both directions (A3).
